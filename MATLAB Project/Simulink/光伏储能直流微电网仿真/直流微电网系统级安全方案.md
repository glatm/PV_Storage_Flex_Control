# 直流微电网系统级安全方案
## ——面向 700V 母线光储直流微电网（烟草绿色园区）

> 适用范围：本方案对应 `PV_Microgrid_700V_DAB.slx` 仿真模型（700V 直流母线 + 48V 负载母线，光伏经 Boost、蓄电池经移相全桥 DAB 接入，负载经 Buck 供电）。
> 标准依据：IEC 60364（低压电气装置）、IEC 62443（工业通信网络安全）、GB/T 35727（中低压直流配电系统）、UL 1741 / IEC 62109（逆变器安全）。

---

## 1. 安全架构总览

| 层级 | 风险 | 本方案对策 |
|---|---|---|
| 设备级 | 过压/欠压损坏变换器与电池 | 母线电压环 + OV/UV 硬件比较 + 软件锁存跳断 |
| 系统级 | 母线短路引发大电流 | 半导体熔断器 + 快速断路器 + 控制限流 |
| 人员级 | 触电、电弧 | IT 接地（浮地）+ 绝缘监测（IMD）|
| 网络级 | 调度指令被篡改 | 边缘侧 MQTT+TLS、只读安全边界（见 §6）|

设计原则：**故障必须就地、快速、选择性切除**，且不能因单点保护误动导致整个园区失电。

---

## 2. 故障分析

### 2.1 700V 母线短路（极间短路）

短路点等效为母线电容 `C_bus` 与源侧通过极小阻抗直接并联。

**故障电流组成：**
1. **电容放电分量**：`i_    
**额定参考**：`I_rated = P/V = 10000/700 ≈ 14.3A`；短路峰值可达额定 **数十倍~数百倍**。

**暂态过程（仿真可见）：**
- 0~100µs：电容放电主导，母线电压骤降、电流陡升。
- 100µs~10ms：控制限流生效，电流被钳位，电压部分恢复。
- >10ms：若保护未动作，半导体与电容热击穿。

### 2.2 单极对地故障（接地故障）

在 IT 系统（浮地）下，单极接地**不构成短路回路**，系统可继续运行（第一故障不跳闸），但：
- 非故障极对地电压升至全母线电压（700V），触电风险升高；
- 若同一极再发生第二点接地 → 演变为极间短路，必须立即跳闸。
- 因此 IT 系统**必须配绝缘监测**，在第一故障即告警。

### 2.3 过载 / 电压越限

- 光照突变导致 PV 功率骤升 → 母线过压；
- 负载投切导致功率缺额 → 母线欠压；
- 电池 SOC 越限 → 充放电能力丧失。

## 3. 保护配置

### 3.1 过压 / 欠压保护（OV/UV）

| 项 | 阈值（700V 母线） | 动作 |
|---|---|---|
| 欠压 UV | < 630V（0.9pu） | 告警；持续 200ms 跳 PV/电池接触器 |
| 过压 OV | > 770V（1.1pu） | 立即限功率；> 800V 跳电池 DAB |
| 紧急过压 | > 850V | 硬件 Crowbar + 跳全部源侧 |

模型实现：比较器 `OV`/`UV` → `FaultOR` 锁存 → 驱动理想开关跳断源侧（见 `build_700V_DAB_microgrid.m` §6）。

### 3.2 短路保护（SC）

**三段式协调（由快到慢）：**
1. **控制限流（<100µs）**：DAB/Boost/Buck 控制器检测过流即把调制比归零（软件第一道闸）。
2. **半导体熔断器（ms 级）**：在电池与母线接口串 `aR` 型快速熔断器，分断能力 ≥ 预期峰值 `I_sc_peak`，`I²t` 小于半导体耐受。
3. **直流快速断路器（<10ms）**：如固态断路器（SSCB）或磁吹断路器，作为可复位主保护，切除后系统可恢复。

模型实现：`OC` 过流比较器（阈值取 `1.5×I_rated≈21A`）→ `FaultAll` → 锁存跳断。

### 3.3 选择性（避免越级跳闸）

- 源侧（PV/Battery）各设独立熔断器 + 电流测量；
- 负载支路（48V Buck 输出）设独立过流；
- 故障定位靠**方向判别**（电流由源流向故障点为正，反向为下游故障），避免母线故障误跳负载。

## 4. 接地方式

### 4.1 TN vs IT 对比（直流系统）

| 方式 | 结构 | 第一故障 | 触电电压 | 适用性 |
|---|---|---|---|---|
| **TN-C / TN-S** | 一点直接接地，另一极经 PE | 构成回路→立即跳闸 | 低（有 PE 钳位）| 简单，但失电风险高 |
| **IT（浮地）** | 系统不与地直接连接，经绝缘监测装置高阻连接 | **不跳闸**，仅告警 | 取决于绝缘状态 | **推荐**：供电连续性好，适园区关键负荷 |

### 4.2 本系统选择：**IT 浮地 + 绝缘监测**

理由：
1. 园区负荷含柔性空调、照明等，**供电连续性优先**——单点接地不应停电；
2. 700V 属于低压上限，浮地可降低单点触电风险；
3. 配合 IMD 实现"第一故障告警、第二故障跳闸"，安全性与可用性兼顾。

**接地实施：**
- 700V 母线两极**均不接 PE**；
- PE 仅用于设备外壳保护接地（设备级安全，与系统级浮地解耦）；
- 48V 母线负极可与 700V 系统参考地单点连接（非隔离 Buck 已共地，见模型 `V48_neg` 共地母线负）。

## 5. 绝缘监测（IMD）

### 5.1 原理（有源电压注入电桥法）

在 700V 母线正负极各经等大监测电阻 `R_m`（典型 `1MΩ`）接至电桥中点 `M`；IMD 在 `M` 注入已知直流测试电压 `V_t`（本模型 `25V`），使 `M` 相对 PE 抬到 `V_t`。测量两极对地电压 `a = V_pg`、`b = V_ng`。

由桥节点 KCL（母线电压 `V = a − b` 恒定）可知：**单工况仅 1 个方程、含 2 个未知 `R_p`、`R_n`，数学上不可同时解出**。工程上采用"对称绝缘"假设 `R_p = R_n = R_iso`，可得闭合解：

```
R_iso = R_m · (a + b) / ( 2·V_t − (a + b) )
```

- 物理意义：健康时 `a + b → 2·V_t`，分母 → 0，`R_iso → ∞`（模型中钳到上限 `1e10Ω`）；绝缘对称下降时 `a + b` 偏离 `2·V_t`，`R_iso` 变小。
- 严格的不对称单极故障需用**两态测量**（测试源在 `+V_t` 与 `0` 间切换，取两组 `a,b` 解两个线性方程）；本仿真采用对称简化，足以演示告警/跳闸逻辑，且计算确定、无歧义。

当 `R_iso < R_alarm`（典型 **< 50kΩ** 报警， **< 10kΩ** 跳闸）时触发保护。

### 5.2 模型实现

`build_700V_DAB_microgrid.m` §6.3 已搭建**完整** IMD（含 Riso 计算子系统）：
- 监测电阻 `R_m_p` / `R_m_n`（各 `1MΩ`）由母线正/负接至中点 `IMD_M`；
- 直流测试源 `Vtest`（`25V`）将 `IMD_M` 抬到 `V_t` 相对 PE(`Gnd`)；
- `Vimd_p` / `Vimd_n` 测两极对地电压 `a`、`b`；
- `IMD_Riso_Calc` 子系统（已建）：内部算 `s = a + b`、分子 `R_m·s`、分母 `2·V_t − s`，得 `Riso = R_m·s/(2·V_t − s)`，经 `Saturation` 钳位 `[1e2, 1e10]Ω`；输出 `Riso`、告警(`<50kΩ`)、跳闸(`<10kΩ`)；
- 子系统**跳闸(Out3)已并入总故障 `FaultMaster`**，与 OV/UV/OC 共同触发三支路理想开关跳断。

### 5.3 告警与动作

| 绝缘状态 | 动作 |
|---|---|
| `R_iso > 100kΩ` | 正常 |
| `50kΩ < R_iso < 100kΩ` | 预警（记录、上报边缘平台）|
| `10kΩ < R_iso < 50kΩ` | 报警（限功率、准备减载）|
| `R_iso < 10kΩ` | 跳闸（第二故障风险）|

## 6. 工程建议

### 6.1 器件选型
- **直流断路器**：额定 `≥1.25×I_rated≈18A`，分断能力 `≥10kA`（按预期短路电流选），优先固态断路器（SSCB，分断 < 1ms）。
- **熔断器**：`aR` 型（半导体保护），`I²t` 曲线低于 IGBT/MOSFET 耐受。
- **电缆**：按 `I_rated` + 降容选截面，杂散电感尽量小（降低 `di/dt` 冲击）。

### 6.2 控制与保护协同
- **限流优先级**：控制限流（软件）→ 熔断器（硬件不可复位）→ 断路器（可复位）。三者 `I²t` 必须协调，避免熔断器在断路器动作前熔断导致不可恢复停电。
- **数字保护**：在边缘侧（Docker+MQTT+InfluxDB）部署保护状态机，OV/UV/SC/IMD 事件写入时序库，Grafana 实时展示，并联动 PuLP 优化调度降功率。

### 6.3 网络安全（边缘原型）
- MQTT 启用 TLS + 设备证书，调度指令需签名；
- 保护动作逻辑在**本地控制器**执行，不依赖云端（防网络中断导致保护失效）；
- 只读暴露测量值，写操作（跳闸/复位）需二次确认。

### 6.4 仿真验证建议
在 `PV_Microgrid_700V_DAB.slx` 中补充：
1. **短路工况**：在 0.1s 将母线正-负经小电阻（如 0.1Ω）短接，验证 `OC` 在 <10ms 内跳断、母线电压回落。
2. **绝缘下降**：逐步增大 `Riso_p` 反向（模拟某极对地电阻降），验证 IMD 在阈值处告警/跳闸。
3. **OV/UV**：将 `Vref` 误设或 PV 过载，验证 OV 动作；将负载拉到远超电池能力，验证 UV 动作。
4. **可迁移性**：对比 48V 系统与 700V 系统的 PI 参数与动态响应，记录电压超调、恢复时间，证明控制策略可迁移（注意 700V 系统时间常数因 C_bus 更大而更慢，PI 需相应放缓）。

**主母线 700V（课题①主体）**

|---|---|---|---|
| 过压 OV | > 770V 限功率；> 800V 跳电池 DAB；> 850V Crowbar 跳全部 | 硬件+软件锁存 | ✅ §3.1 |

**每项保护的检测逻辑 + 动作序列（答辩常被追问，补充于此）**
- **OV/UV**：采样母线电压 → 与阈值比较 → 软件比较器输出锁存信号；OV 分级（限功率→跳 DAB→Crowbar），UV 带 200ms 延时防误动。
- **SC/OC**：采样桥臂电流 → `OC` 比较器（硬件级 <100µs 限流）→ aR 熔断器（ms 级，承受短时可承受浪涌）→ 直流专用快速断路器（<10ms 彻底隔离）。
- **IMD**：IT 浮地系统注入低频/直流检测电流 → 测对地绝缘电阻 R_iso → 50kΩ 告警 / 10kΩ 跳闸（防触电与电弧）。

**选择性（避免越级跳闸）**：源侧各设独立熔断器 + 电流测量，负载支路独立过流，靠**方向判别**定位故障区段——已计入 §3.3。

### 8.1 与课题④边缘原型对接（落地细节）
§6.2–§6.3 已规划"边缘侧（Docker+MQTT+InfluxDB）部署保护状态机，OV/UV/SC/IMD 事件写入时序库，Grafana 展示，并联动 PuLP 优化调度降功率"。**与 `docs/云端部署指南.md` §8、`docs/项目说明.md` §4.6 的课题④边缘栈方案一致**——安全方案已先行，缺的只是把 MQTT/Grafana/InfluxDB 代码补出来（当前仅 FastAPI 云 API 已落地）。

**保护事件上送的具体对接方式（供补代码时直接照做）**
- 保护状态机每产生一个事件，经 MQTT `publish` 到 `pv/{site}/alarm`，payload 例：
  ```json
  {"ts":1690000000, "type":"OV", "level":"trip", "bus":"700V", "val":812.3}
  ```
- `mqtt_bridge` 订阅 `pv/+/alarm`（QoS2）→ 写 InfluxDB（tag `metric=alarm`）+ 触发 Grafana 告警；
- 同时联动 PuLP：收到 `OV`/`SC` 时调用 `publish_command(site, "ess", {"p_limit": 0.0})` 降功率/隔离，防止级联。
- **网络安全**：MQTT 启 TLS + 设备证书（§6.3），**保护动作本地执行不依赖云**——断网时就地保护照常动作，云只负责可视化与优化降功率建议。
