## 一、§17 电池 OCV 钳位关键坑（原笔记 L1266）

** 700V 电池的 OCV≈Vnom·SOC 钳位（本项目关键坑）**：本项目 700V 电池模型 OCV 近似随 SOC 线性，$OCV\approx V_{nom}\cdot SOC$——SOC=100%⇒OCV≈700V（母线可建到 700V），SOC=50%⇒OCV≈350V（会把母线钳在 350V）。这正是 把电池初始电荷设为 50Ah(=100%SOC) 后母线才升到 700V 的根因；若初始电荷 25Ah(=50%SOC) 则母线被钳在 ~350V。

## 二、§26.17 700V 开环建压搭配

#### 26.17 700V 开环建压搭配（Boost 直上 700V + 电池支撑，执行版）

- **整体功能**：让 700V 母线"建得起来"——Boost 从 PV Vmp≈432V 升到 700V（D≈0.383，升压比≈1.6 倍），满 SOC 电池并联母线做电压支撑。这是 验收"能跑起来的 700V 初始模型"的核心搭配。（早期设计曾误按 PV 25V 算成 28 倍升压、D≈0.964，与模型不符）
- **模块与角色**：
- Boost 功率级（26.1 同构，参数按 700V 重算）：升压比≈1.6 倍（Vmp≈432V→700V），由 CCM 公式 $V_{out}=V_{in}/(1-D)$ 得 D≈0.383——占空比适中、余量充足；早期设计曾误按 PV 25V 算成 28 倍、D≈0.964，二极管导通窗口极窄（仅关断 3.6% 时间）、对死区/时序极敏感——那是该早期设想的隐患，实际 432V 输入已规避。电感 L、电容 C 仍取 500µH/500µF（深 CCM 余量大，不必改）。
-`Battery_700V`（Vnom=700V、AH=50、**charge=50Ah 即 SOC=100%**、R1=0.02Ω）：直接并联母线。⚠️ **OCV≈Vnom×SOC 钳位规则**：电池是"硬"电压源，母线=电池端电压；SOC=50% → OCV≈350V 会把母线死死钳在 350V，Boost 顶不上去。
-`Ramp`(slope=2000)+`Saturation`(0~700)：700V 参考软启动（0.35s 到顶）。
- 求解器：`daessc`/变步长/`MaxStep=1e-6`/`StopTime=1.0s`（开环建压慢，短窗看不到稳态）。
- **连线**：PV → Boost → 700V 母线节点；电池、Cout、负载全部并联在该节点；节点挂 Electrical Reference。
- **验收基准**：母线终值 699.76V、稳态纹波 0.111V（0.016%）。
- **升压比与占空比**：Vmp≈432V→700V 升压比≈1.6 倍，$D=1-432/700\approx0.383$，占空比适中、余量充足（早期误按 25V 输入得 28 倍、$D\approx0.964$ 为过时设想）。
- **OCV 钳位铁律**：电池是"硬"电压源，母线=电池端电压；$SOC=50\%\to OCV\approx350V$ 把母线死钳在 350V，Boost 顶不上去——故必须 SOC=100%（charge=50Ah）。
- **软启动**：Ramp slope=2000 → 0→700V 在 0.35s 升完。
- **求解器**：daessc/变步长/MaxStep=1e-6/StopTime=1.0s（开环建压慢）。
- **验收**：母线终值 699.76V、纹波 0.111V（0.016%）。

## 三、Day13 电池 SOC 钳位

#### 电池 SOC 钳位（后期才发现的卡点）

- **触发现象**：电池初始电荷`25Ah(50%)`母线怎么都建不到 700V。
- **报错/异常**：**无 MATLAB 报错**，但母线被钳在 ~350V，Boost 顶不上去。
- **根因**：电池 OCV 源经 0.02Ω 内阻与 Cout 同节点，KVL 强制母线=OCV；`25Ah(50%)`→OCV≈350V，把母线钳在 350V。
- **修复**：改初始电荷`50Ah(100%)`→OCV≈700V，母线正常升到 700V（验收：699.76V、纹波 0.111V/0.016%）。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩（原理）*：电池 OCV 源经 0.02Ω 内阻与 Cout 同节点，KVL 强制母线=OCV；25Ah(50%)→OCV≈350V 把母线钳在 350V；50Ah(100%)→OCV≈700V 母线正常升到 700V。
  - *如何从根本上避免*：改初始电荷 50Ah(100%)→OCV≈700V。
  - *对应理论/模块*：电池 OCV 与母线电压耦合（详见本节末"电池 SOC 钳位原理"）。

#### 电池 SOC 钳位原理（本次解释，备忘）

电池`Battery_700V`（Simscape`batteryecm_lib/Battery`）参数：`Vnom=700V``AH(容量)=50Ah``charge(初始电荷)`原 25Ah(50%)→现 50Ah(100%)、`R1(内阻)=0.02Ω`。

- 该电池 OCV 近似线性：`OCV(SOC)≈Vnom×SOC`→ 50%→350V、100%→700V。
- 电容 Cout 与电池跨同一对节点，母线电压被电池 OCV 强制拉平（KVL）。电池是"OCV 源串联 0.02Ω 内阻"的二端元件，Boost 本质上往该节点灌电流，但节点电压由更"硬"的电池电压源说了算 → 母线=电池端电压。
- 故 SOC=50%/OCV=350V → 母线被钳 350V，Boost 只能给电池充电、顶不上去；SOC=100%/OCV=700V → 母线自然到 700V（内阻仅 0.02Ω，故母线几乎等于 OCV）。

### 物理底座踩坑

#### 唯一接地规则缺失

- **触发现象**：搭建含多个功率地、或漏接`Electrical Reference`的电路。
- **报错/异常**：Simscape 初始化报错（缺参考节点类），或电压悬空/全零、仿真不收敛。
- **根因**：Simscape 基于节点电压法，必须有一个唯一参考零电位定义 KCL/KVL 基准；多参考或零参考会使方程欠定。
- **修复**：所有功率地统一接唯一一个`Electrical Reference`删掉多余的接地块。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩*：节点电压法把电路写成矩阵方程 $A x = b$，参考点就是 $b$ 的基准（令某节点电压=0）。多参考或零参考 → 方程秩不足（欠定/奇异），求解器无法唯一解。MathWorks 官方文档明确写有："A model with electrical elements must contain at least one Electrical Reference block"，每个拓扑独立的电气回路至少需一个 `Electrical Reference`。
  - *如何从根本上避免*：坚持"单点接地"——整个功率网络只接唯一一个 `Electrical Reference`；多个地模块之间若需隔离用 Isolation/Transformer 而非并接。地线也构成电流闭合回路，不能省。
  - *对应理论/模块*：第一篇"Simscape 物理建模三规"之"唯一接地规则"。

#### 物理域与信号域混淆

- **触发现象**：把 Simulink 信号线(细线)直接连到 Simscape 物理连线(粗线)，或拿信号线去驱动 MOSFET 栅极。
- **报错/异常**：编译/初始化报域类型不匹配，或 MOSFET 栅极无有效驱动、开关行为诡异。
- **根因**：Simulink 信号(无量纲)与 Simscape 物理网络(带 V/A/W、遵 KCL/KVL)是两套域，不能直接相连；栅极是电气端口，须由物理电压源驱动。
- **修复**：域间互转用 PS-Simulink Converter / Simulink-PS Converter；MOSFET 栅极接物理电压源(如 Controlled Voltage Source 或 CVS 驱动)。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩*：Simscape 是"物理网络"建模，连线上承载的是带单位的 Through/Across 变量（电流/电压），遵循广义 KCL/KVL；Simulink 信号线是纯数学标量，两者无法直接对接。栅极是电气端口，必须由物理电压源驱动。
  - *如何从根本上避免*：跨域必须过 `PS-Simulink Converter`（物理→信号）与 `Simulink-PS Converter`（信号→物理）；MOSFET 栅极接 `Controlled Voltage Source` 等电气源。口诀"域不对，转换器；栅要电，源来给"。
  - *对应理论/模块*：第一篇"物理域 vs 信号域"；转换器本质上在做"数学量 ↔ 物理量（含单位）"的桥接。

#### 传感器接线反了（电流串、电压并）

- **触发现象**：电流/电压传感器接反——电流传感器并联、电压传感器串联。
- **报错/异常**：**无报错**，但电流/电压读数全错，连带闭环控制算错。
- **根因**：电流须串联测支路电流、电压须并联测两端电位差；反接破坏测量的物理意义。
- **修复**：电流串、电压并；Converter 接口不能空。口诀"电流串、电压并、Converter不能空"。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩*：电流是 Through 变量，必须串入支路测"流过的量"；电压是 Across 变量，必须并接在两节点间测"电位差"。反接=测量对象错误，所以**无报错但读数全错**。
  - *如何从根本上避免*：电流串、电压并；Simscape 测量端口也需经 Converter 引出到 Simulink，接口不能空。
  - *对应理论/模块*：第一篇"传感器电流串、电压并"；Through/Across 变量概念。

#### 二极管方向反接

- **触发现象**：Boost 续流二极管阳极/阴极接反。
- **报错/异常**：**无报错**，但 MOSFET 导通时形成 母线→二极管→MOSFET→地 短路，电流/电压异常。
- **根因**：二极管须"阳极→开关节点、阴极→输出"才能续流；反接使其导通时把母线直接短路到地。
- **修复**：二极管方向改为 阳极→开关节点、阴极→输出。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩*：Boost 拓扑中，MOSFET 导通时电感储能、二极管截止；MOSFET 关断时电感续流，电流经二极管向输出供电。二极管必须阳极接开关节点、阴极接输出，才在关断时正向导通续流。反接则 MOSFET 导通瞬间二极管也导通 → 母线经二极管直抵地（短路）。
  - *如何从根本上避免*：记住"电感电流往哪流，二极管就给哪开路"——续流方向=输出方向。
  - *对应理论/模块*：第一篇"Boost 伏秒平衡与二极管方向"。

#### 电感开路 / 负载不共地

- **触发现象**：电感引脚虚焊/开路，或负载另一端接了孤立的接地模块（未与功率地相连）。
- **报错/异常**：**无报错**，但漏极电压只有极窄振铃而非方波（电感开路），或负载电流为零（不共地）。
- **根因**：电感开路破坏开关波形；所有功率地必须共同一个 Electrical Reference，孤立地模块使回路断开。
- **修复**：确保电感连通；所有功率地接到唯一一个 Reference。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩*：电感开路 → 开关动作无储能/释能通路，漏极看不到方波；负载不共地 → 回路断开，电流为零。所有功率地必须汇聚到同一 `Electrical Reference`。
  - *如何从根本上避免*：搭电路时先确认每个功率节点都汇入唯一地参考；用 Probe/测量确认回路闭合。
  - *对应理论/模块*：第一篇"唯一接地规则"。

#### Solver Configuration 物理端口未接地（2025b）

- **触发现象**：2025b 里 Solver Configuration 模块的物理端口没接 Electrical Reference。
- **报错/异常**：初始化报错（Solver Configuration 物理端口须接地）。
- **根因**：2025b 起强制 Solver Configuration 的物理端口必须接地，否则求解器无参考。
- **修复**：把 Solver Configuration 的物理端口接到 Electrical Reference（或直接接地）。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩*：Solver Configuration 作为网络求解环境配置块，其物理端口须接到电气参考才能定义求解基准；2025b 起改为强制。
  - *如何从根本上避免*：新建模型养成"先放 Solver Configuration + Electrical Reference"的习惯；物理端口连地。
  - *对应理论/模块*：Simscape 求解器配置文档。

#### 模块参数名写错（R2025b）

- **触发现象**：用脚本 set_param/get_param 设模块参数，参数名按老版本/直觉写。
- **报错/异常**：脚本报错（参数名无效/未找到），或 add_line 报"参数不足"。
- **根因**：R2025b 参数名有变——Rate Limiter 是 RisingSlewLimit/FallingSlewLimit（非 RisingSlewRate）、无 SampleTime；PID 饱和是 LimitOutput/UpperSaturationLimit/LowerSaturationLimit/AntiWindupMode；find_system 返回单元格须 sc{k} 取元素；add_line 传第4参'auto'会报参数不足。
- **修复**：用正确参数名；get_param 先查实际参数列表；add_line 用端口句柄、勿传多余参。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩*：版本升级改了参数名（R2025b 中 Rate Limiter / PID 饱和命名变动）。
  - *如何从根本上避免*：脚本里先用 `get_param` 列出实际参数名再 `set`；不要凭记忆写。`find_system` 返回 cell 用 `sc{k}` 取元素；`add_line` 用端口句柄、勿传第 4 参。
  - *对应理论/模块*：MATLAB 脚本自动化建模。

#### MATLAB 崩溃恢复

- **报错/异常**：进程消失，未手动保存的模型丢失。

  - *对应理论/模块*：Simulink 自动保存机制。

### 双向变换器踩坑

#### 浮地驱动接错（Vgs_top 负极误接地）

- **触发现象**：半桥上管 S1_top 的驱动电压 Vgs_top 负极误接到固定地（而非上管源极 S1_top_source）。
- **报错/异常**：**无 MATLAB 报错**，但 Vgs_top 跌至 −900V、电池电流瞬间数千安冲击（🔴 最高危，会烧管/炸电容）。
- **根因**：上管（高边）源极电位随开关节点浮动，其驱动必须"自举/浮地"——驱动负压参考点应接源极；误接固定地使 Vgs 出现巨大负偏，驱动完全错乱。
- **修复**：Vgs_top 负极接 S1_top 源极（自举/浮地驱动）。口诀"上管跟源跑，下管踩实地"。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩（原理）*：上管（高边）源极电位随开关节点 $S_v$ 在 $0 \leftrightarrow V_{bus}$ 间跳变。$V_{gs}$ 应=$V_g - V_{source}$；若驱动负极误接固定地，则 $V_{gs}=V_g-0=V_g$，但上管真正需要的驱动是相对其源极的浮空电压。当源极被母线抬高到 $V_{bus}$ 时，固定地参考使驱动出现 $V_{bus}$ 量级的负偏（本项目实测 −900V），完全错乱，下管等效常通 → 电池经下管短路到地 → 数千安冲击（🔴 最高危）。
  - *如何从根本上避免*：上管驱动必须"自举/浮地"——驱动负压参考点接上管源极（本项目"Vgs_top 负极接 S1_top 源极"）。口诀"上管跟源跑，下管踩实地"（下管源极本就接地，可用普通低边驱动）。
  - *对应理论/模块*：半桥双向 Buck-Boost 的浮地驱动；自举电容/隔离驱动原理。

#### 死区时间未加

- **触发现象**：半桥/全桥互补 PWM 驱动未插入死区时间。
- **报错/异常**：仿真碰巧不报错（本项目 48V 当前无死区"侥幸"通过，但不严谨）；真实 700V 硬件下会直通炸管。
- **根因**：上下管共母线/共源极，关断→开通切换瞬间若两管同时导通，形成 Vbus→HS→LS→GND 低阻通路（Shoot-through），di/dt 极大、数微秒热失控。
- **修复**：互补驱动插入 0.5~1µs 死区；700V 系统必须加（≥300ns），否则直通风险极高。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩（原理）*：上下管共母线/共源极。MOSFET 有 $t_{off} > t_{on}$ 的固有延迟，互补 PWM 翻转瞬间若两管短暂同时导通，形成 $V_{bus} \to HS \to LS \to GND$ 低阻通路（Shoot-through），di/dt 极大、数微秒内热失控炸管。TI 应用笔记指出：即便 10 ns 级时序偏差在 650V/30A 系统即可诱发数百安直通电流。
  - *如何从根本上避免*：互补驱动插入死区（本项目 48V 实测"侥幸"通过，但 700V 必须≥300ns、建议 0.5~1µs）；死区是硬件级保险，不能靠软件侥幸。
  - *对应理论/模块*：半桥直通机理、死区时间、米勒效应误开通。

### PI 闭环踩坑

#### 代数环（Transport Delay 破环）

- **触发现象**：Vbus→误差→PI→占空比→MOSFET→Vbus 形成无延迟环路（反馈直接回灌）。
- **报错/异常**：仿真报警/不收敛，或出代数环 warning、结果异常。
- **根因**：闭环里误差信号未经任何延迟直接驱动被控对象，构成代数环，求解器无法迭代。
- **修复**：误差路径插 Transport Delay(1μs) 打破环（物理上对应采样/计算延迟）。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩（原理）*：闭环 `Vbus→误差→PI→占空比→MOSFET→Vbus` 中，若误差到占空比的路径无任何时间延迟，求解器在同一时刻需同时满足"输出由输入算"和"输入由输出算"的相互依赖（代数约束），迭代不收敛。MathWorks 文档：可在反馈环插入 `Unit Delay` / `Transport Delay` 破环。
  - *如何从根本上避免*：误差路径插 `Transport Delay(1μs)`，物理对应采样+控制计算延迟（数字控制器本就有 1 个采样周期延迟）。注意：连续系统破环宜用一阶传递/小时间常数滤波而非 `Memory`（避免引入离散伪差）。
  - *对应理论/模块*：第一篇"代数环与 Transport Delay 破环"；采样系统固有延迟。

#### 数据类型不匹配

- **触发现象**：Relational Operator 输出直接连 Gain（或其它需 double 的块）。
- **报错/异常**：编译报错（数据类型不匹配 / 不支持布尔运算）。
- **根因**：Relational Operator 输出是布尔(bool)，不能直接进需要 double 的算术块。
- **修复**：插 Data Type Conversion 把布尔转成 double 再进 Gain。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩*：Relational Operator 输出 bool，算术块（Gain 等）要 double，类型不兼容。
  - *如何从根本上避免*：插 `Data Type Conversion` 转 double 再进算术块。
  - *对应理论/模块*：Simulink 数据类型系统。

#### PID 限幅与积分初值冲突

- **触发现象**：PID 输出下限设 0.1，同时积分初值设 0。
- **报错/异常**：仿真行为异常（输出被钳在限幅边界、控制失效）。
- **根因**：输出下限 0.1 与积分初值 0 冲突——积分从 0 起步但输出被下限 0.1 钳住，初始段控制量错。
- **修复**：下限改 0（或积分初值设合理中间值），消除冲突。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩*：输出下限 0.1 与积分初值 0 矛盾——积分从 0 起步，但 PID 输出被下限钳在 0.1，初始段控制量被强制抬高，控制意图失真。
  - *如何从根本上避免*：下限改 0 或积分初值设合理中间值（如 0.5）；限幅边界别与初值打架。
  - *对应理论/模块*：PID 结构（限幅与积分耦合）。

#### 电池 Beta 参数报错

- **触发现象**：用`Battery (Table-Based)`填了"标称电压 48V"但"初始电荷 40Ah"对应的 SOC 不在同一条 OCV-SOC 曲线上。
- **报错/异常**：Simscape 报 Beta 参数错误（OCV-SOC 不匹配类报错）。
- **根因**：电池块靠 OCV-SOC 查表工作；标称电压与初始电荷(→SOC)必须落在同一组查表数据，否则数学上无解。
- **修复**：临时用**无限容量模式**（SOC 固定、不做 SOC 更新）规避；MILP/真实调度须改回有限容量并填好匹配的 OCV-SOC 表。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩*：`Battery (Table-Based)` 靠 OCV-SOC 查表定义工作点；标称电压与初始电荷(→SOC)必须落在同一组查表。否则数学上无一致解 → Beta 报错。
  - *如何从根本上避免*：临时用无限容量模式（SOC 固定）；真实调度须填好匹配的 OCV-SOC 表。
  - *对应理论/模块*：Simscape Battery 等效电路模型（ECM）。

#### SOC 零偏累积漂移（库仑计数须 OCV 锚定）

- **触发现象**：用纯库仑计数估计 SOC，且电流传感器存在零偏。
- **报错/异常**：**无 MATLAB 报错**，但 SOC 随时间持续漂移、初始 SOC 错则永远错，长运行后估计严重失真。
- **根因**：SOC[k]=SOC[k-1]−I·Δt/Qnom，零偏在积分中累积；LFP 中段 OCV 近乎"平顶"，难以靠电压反推校正。
- **修复**：定期用 OCV **锚定**（静置后终端电压→OCV→查表，或上电/满电校正）；生产级用 EKF（`SOC Estimator (Kalman Filter)`块）实时补偿；无限容量模式只是规避，真实电池须正视此漂移。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩（原理）*：库仑计数
    $$SOC[k]=SOC[k-1]-\frac{I\cdot\Delta t}{Q_{nom}}$$
    零偏 $\Delta I_{offset}$ 在积分中累积：$\Delta SOC_{drift}=\frac{\Delta I_{offset}\cdot t}{Q_{nom}}$，随时间线性放大。LFP 中段 OCV 近乎"平顶"（约 3.2~3.3V 横跨 10%~90% SOC），电压法难以反推校正。权威 BMS 资料一致指出：LFP 实时 OCV 估计极不可靠（中段电压几乎不变），必须 OCV 复位 + EKF（扩展卡尔曼滤波）才能长效准确。
  - *如何从根本上避免*：定期 OCV 锚定（静置 30~60min → 端电压 → 查表，或上电/满电校正）；生产级用 `SOC Estimator (Kalman Filter)` 实时补偿。无限容量模式只是规避，真实电池须正视漂移。
  - *对应理论/模块*：第一篇"库仑计数 vs OCV 锚定 vs EKF"；BMS SOC 估计三法（OCV 查表 / 库仑计数 / 卡尔曼滤波）。

#### PI 调参 P 太小反而超调更大

- **触发现象**：PI 的 P 取得很小，指望增大 P 压超调。
- **报错/异常**：**无报错**，但启动首峰极高（物理冲击超调）或持续多周期振荡（控制超调）。
- **根因**：电力电子启动有光伏满功率涌入电容的**物理冲击**，P 太小压不住→超调更大（与"P 大超调大"直觉相反）；或 P/I 不匹配导致持续振荡。
- **修复**：先调 P 后调 I；根本靠**软启动(Ramp Vref)**吸收物理冲击，而非死磕 PI 增益。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩（原理）*：电力电子启动有光伏满功率涌入电容的**物理冲击**（不可被 PI 消除，只能被软启动吸收）。P 太小 → 对误差响应弱 → 占空比抬不上去 → 母线被物理冲击推得更高（超调更大），与"P 大超调大"的线性直觉相反。
  - *如何从根本上避免*：先调 P 后调 I；根本靠**软启动(Ramp Vref)**吸收物理冲击，而非死磕 PI 增益。
  - *对应理论/模块*：第一篇"软启动"；物理冲击 vs 控制超调的区别。

#### 软启动极性 / Ramp 斜率

- **触发现象**：软启动斜坡极性/对齐错（error 符号翻反，或各源斜坡没对齐）。
- **报错/异常**：**无报错**，但启动冲击大、出现"一方已建立另一方为零"的瞬态冲击。
- **根因**：error=Vbus−48 符号必须正确；软启动斜坡须对齐各源，否则初始条件不匹配产生大误差。
- **修复**：error 用 Vbus−48（不要翻）；软启动加在设定值(Ramp Vref)，**不要加在 PID 输出(Rate Limiter)**。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩*：error=Vbus−48 符号必须正确（负反馈方向）；软启动斜坡须各源对齐，否则初始条件不匹配产生大误差冲击。
  - *如何从根本上避免*：error 用 Vbus−48（不要翻）；软启动加在设定值(Ramp Vref)，**不要加在 PID 输出(Rate Limiter)**。
  - *对应理论/模块*：第一篇"软启动对齐"。

### 扰动测试踩坑

#### 误判 Subtract1 符号反了

- **触发现象**：把误差定义`error = Vbus − 48`翻成`error = 48 − Vbus`。
- **报错/异常**：**无报错**，但 Vbus 从 78V 降到 62V、软启动看似生效，Ibat 仍钉死在 −66.8A。
- **根因**：符号翻转只是让数值"碰巧好看"，但设定值闭环下 PID 仍把占空比顶到饱和，电池持续灌死电流——问题不在误差极性，而在 PID 增益不足/执行器饱和。

- **⟦补充：根因原理 / 根治 / 对应知识⟧**

  - *如何从根本上避免*：恢复 `error = Vbus − 48`；真解决靠把 PID 增益调到能让 duty 顶到 1。

#### 误判抗饱和能解决

- **触发现象**：给设定值闭环加`Limit output [0,1]`+ 抗积分饱和（clamping），指望解决启动冲击。
- **报错/异常**：**无报错**，启动仍冲到 106V；更糟的是**扰动时 Vbus 漂到 54.5V**（限幅把 PID 调节能力锁死）。
- **根因**：抗饱和保护只在"已饱和且误差同向"时暂停积分；本项目增益不足导致常态性饱和，抗饱和反而让控制器在扰动下丧失调节能力（损害扰动响应）。抗饱和不是万能。
- **修复**：放弃单纯靠抗饱和；先解决增益不足（PID 调到能让 duty 顶到 1），再视工况决定要不要抗饱和。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩*：抗饱和只在"已饱和且误差同向"时暂停积分；本项目增益不足导致常态性饱和，抗饱和反而让控制器在扰动下丧失调节能力（损害扰动响应）。
  - *如何从根本上避免*：放弃单纯靠抗饱和；先解决增益不足(PID 调到能让 duty 顶到 1)，再视工况决定要不要抗饱和。
  - *对应理论/模块*：PID 抗积分饱和（clamping）的适用边界。

#### 真根因：PID 增益太小 duty 到不了 1（78V）

- **触发现象**：D1 模型（设定值闭环）母线稳在 78V，PID 怎么调都压不下来。
- **报错/异常**：**无报错**，但 Vbus 恒定 78V，电池持续放电、母线远高于 48V。
- **根因**：调压执行器是电池侧变换器，特性 duty=1→钳 48V、duty<1→放电→母线>48V；"调到 48V"="让 PID 把 duty 顶到 1"="PID 输出≥1"。D1 原 P=0.02/I=0.002 在 Vbus=78V 时 P 项≈0.6、I 项≈0.0036，PID 输出≈0.6 永远到不了 1 → duty 卡 0.6 → 78V。

#### 三、duty=1钳位根因

##### 3.1 现象

在加入软启动和扰动后，Vgs_top长期处于0V（占空比0）、Vgs_bot长期处于12V（占空比1），即**下管常通、上管常断**。

##### 3.2 根因

**误差极性定义与控制方向不匹配**。

- 原误差定义：`error = Vref - Vbus`
- 软启动初期：Vref从0斜坡上升，Vbus≈48V，所以error为负值。
- 负误差使得PI输出试图减小，但输出限幅下限为0，PI输出被**饱和钳位在0**。
- 占空比D=0 → 上管驱动信号恒为0V → 下管互补驱动恒为12V → 下管常通。
- 下管常通 = 电池端电感直接通过下管短路到地，变换器失去调节能力。

**本质**：**PI输出被推至并锁死在限幅边界，系统进入饱和死区，无法退出。**

##### 3.3 为什么增大PI参数后恢复正常？

- 增大P：同样误差下产生更大的控制量，更快脱离0附近。
- 增大I：积分器快速累积，即使P不够，积分项也能迅速推高输出。
- 使用P=0.05，I=2.0后，PI输出在极短时间内跳出0饱和区，占空比恢复正常，上下���驱动恢复互补方波。

##### 3.4 如何预防？

- **正确匹配误差极性与被控对象**：确保负反馈方向正确。本系��中，`error = Vbus - Vref`才是正确的负反馈（Vbus偏高→error为正→应增大上管占空比→降压）。
- **合理设置积分初始值**：将PID积分初始值设为一个合理的中间值（如0.5），避免从0起步。
- **使用软启动匹配初始状态**：如果Vref从0开始，应将母线电容初始电压也设为0，或让Vref从48V开始。

> **⟦补充⟧** 这条本质是"饱和死区"——当 PI 输出被推至并锁死在限幅边界，系统进入不可控区。防护三件套：① 误差极性必须与控制方向匹配（本项目 `error=Vbus−Vref` 才是正确负反馈）；② 积分初值给合理中间值避免从 0 起步；③ 软启动匹配初始状态（Vref 从 0 则母线电容初压也设 0，或 Vref 从 48V 起）。参考：第一篇"PI 饱和死区"与"软启动对齐"。

#### 四、换结构必须重整定增益（最核心教训）

##### 4.1 为什么换结构后原来的PI参数失效？

**系统传递函数改变了。**

| 变化 | 影响 |
| -------------- | -------------------------- |
| 加入软启动（Vref从0斜坡） | 启动阶段出现大误差，可能使PI输出饱和 |
| 加入扰动（光照阶跃、负载投切） | 系统承受大幅阶跃扰动，对PI的带宽和相位裕度提出新要求 |
| 修改误差极性 | 控制器增益符号可能需翻转 |
| 修改输出限幅 | 饱和值影响抗积分饱和行为 |

**原来的P=0.02，I=0.002（模型实测值）是在“恒定Vref=48V、无扰动、固定负载”工况下凭经验试出来的**。当工况变化后，这个参数组合不再适用。

##### 4.2 重整定原则

- **不要留恋旧参数**：新结构需要重新测试P和I的合适范围。
- **先调比例，再调积分**：在扰动工况下，逐步增大P直到响应快且不振荡，再逐步增大I消除静差。
- **关注饱和**：如果控制量长时间停在限幅边界，说明控制力不足或极性错误，需要增大增益或修正极性。
- **一次只改一个环节**：比如先固定光照和负载，只调PI；PI调好后再加入软启动或扰动，逐步验证。

##### 4.3 本次教训提炼

> 每一次模型结构变动（加软启动、改反馈极性、增扰动源、变负载），都必须重新审视PI参数的适应性。控制参数是“生长”在具体结构之上的，换了土壤，原来的种子就可能不发芽。

> **⟦补充⟧** 控制参数是"生长"在具体结构之上的；任何结构变动（加软启动/改反馈极性/增扰动源/变负载）都须重新审视 PI 适应性。可量化的整定判据：若控制量长时间停在限幅边界，说明控制力不足或极性错（本项目中=PID 顶不到 1）。一次只改一个环节，逐步验证。参考：扰动测试踩坑「真根因：PID 增益太小」。

#### DAB 漏感没体现 → 功率传不过去（最易犯的错）

- **触发现象**：DAB 搭好，给固定移相角 φ，但副边没功率送出 / 母线建不起来。
- **报错/异常**：**无 MATLAB 报错**，但 $i_L$ 无变化、功率传不过去。
- **根因**：DAB 的串联电感 $L$ 就是**功率传输媒介**（靠两端电压差驱动电流传功率）；Simscape 线性变压器若设成"理想无漏感"，或忘了额外串 $L_k$，就没有传功率的媒介。
- **修复**：在变压器里体现漏感（`Mutual Inductance`漏感参数）或外加串联`Inductor`（几十 µH，按报告 §23.2 公式算）。
- **⟦补充：根因原理 / 根治 / 对应知识⟧**
  - *为什么会踩（原理）*：DAB 的串联电感 $L$ 是**功率传输媒介**，靠两端电压差驱动电流传功率。单移相(SPS)下功率
    $$P(\phi)=\frac{n V_1 V_2 f_{sw}}{L_{tot}}\,\phi(1-2\phi)$$
    （$\phi$ 为移相占空比分数，0~0.5）。Simscape 线性变压器若设"理想无漏感"或忘串 $L_k$，就没有传功率的媒介。
  - *如何从根本上避免*：变压器里体现漏感（`Mutual Inductance` 漏感参数）或外加串联 `Inductor`（几十 µH，按报告 §23.2 公式算）。
  - *权威要点*：imperix DAB 设计指南指出 $L_{tot}$ 指折算到原边的总电感（漏感+外串）；ZVS 需满足 $\frac{1}{2}L_{tot}I_{pk}^2 > 2 C_{oss}V^2$。

### Day14 700V 闭环稳压踩坑（PV_Microgrid_Day14_700V.slx）

> 本天把 Day13 的开环 700V 模型接上"前馈+PI 复合闭环"（§26.21）。实测可用的关键参数与坑如下；详细操作见 `Day14_闭环稳压操作文档.md`（如已找回）与 `Day13到Day14_15升级操作方案.md` §1。

#### 前馈输入必须接实测 Vbus，绝不接参考电压

- **现象**：前馈 `Fcn(1-432/u)` 的 u 若接参考电压 Vref，光照/负载突变时前馈给的是"目标值"而非"实际值"，动态过程过驱动、母线 overshoot。（早期设计曾按 PV 33V 写 `1-33/u`，与模型 432V 不符）
- **根因**：前馈本意是"按当前实际工况算基准占空比"，必须吃实测 Vbus；接 Vref 等于用没发生的目标去驱动，逻辑自相矛盾。
- **修复**：u = 实测 Vbus（经 `FF_Delay` Transport Delay 1µs）→ `Saturation1[45,700]` → `Fcn(1-432/u)` → `Duty_Sum(in2)`（§26.21）。

#### 前馈 Fcn 必须加输入下限 Saturation[45,700]

- **现象**：负载突卸/短路瞬间 Vbus 可能骤降，u→0 使 `432/u` 发散、占空比瞬飙到上限甚至 NaN（早期设计按 33/u，发散更慢但同样危险）。
- **修复**：`Saturation1` 下限 45V（保护 `432/u` 分母，防 Vbus 骤降→∞；早期设计按 33/u）、上限 700V；这是复合前馈的标配保险。

#### Duty_Sat[0.05,0.968] 总占空比限幅不可省

- **现象**：去掉总限幅，升压比大时占空比易越界（<0.05 或 >0.968），Boost 失稳甚至仿真报错（早期误设想 28 倍升压、D≈0.964 时此风险最突出；实际 Vmp≈432V→700V D≈0.383 已远离上限）。
- **根因**：0.968 对应最大升压比安全上限（早期按 Vin≈33V 设想 $D=1-33/700\approx0.953$，留裕量到 0.968；实际 PV Vmp≈432V 前馈基准 $D\approx0.383$，0.968 仅为安全封顶）；下限 0.05 防深度 DCM/反向。限幅放在 `Duty_Sum` 之后、PWM 比较器之前。

#### PID 增益必须按 pu 缩小（最终定稿 P=2e-4 / I=0.1，≠48V 的 0.05/2.0；早期过渡值 7e-4/0.03 已弃用）

- **现象**：把 48V 闭环的 P=0.05/I=2.0 直接搬来，700V 环路增益被放大约 15 倍，母线剧烈振荡/发散。
- **根因**：PI 增益与电压等级成反比（标幺化 pu 整定，§21.0 标幺化）；700V 下要用小得多的 P、够大的 I。最终定稿 **P=2e-4 / I=0.1**（早期过渡值 7e-4/0.03 已弃用，`Limit output [-0.3,+0.05]` + `Anti-windup=Clamping`）。
- **教训**：换电压等级=换结构，必须重定增益（呼应 48V 的"duty=1 钳位根因 / 换结构须重定增益"）。

#### Subtract 误差符号 e = Vref − Vbus（反了变正反馈）

- **现象**：符号接反，母线低了 PID 反而减小占空比、越低越灌不进 → 正反馈发散。
- **修复**：`Subtract(+-)` 设 `Vref` 接 `+`、`Vbus` 接 `−`；接线口诀"误差=参考−实测"（§26.4）。

#### 软启动一律加在设定值端，绝不加 PID 输出

- **现象**：`Rate Limiter` 加在 PID 输出会放大上电冲击、诱发积分饱和。
- **修复**：`Ramp(slope=2000) → Saturation(0~700) → Subtract(+)`，参考从 0 缓升到 700V；PID 输出原样进 `Duty_Sum`（§8/§8.1）。

#### 求解器塌缩：变步长 daessc/ode23t 步长压到 1e-18

- **现象**：开关硬事件处变步长被迫缩到 1e-18 仍不满足误差，"卡死"或极慢。
- **修复**：全局 `ode1be` 固定步长 `1e-6` + Simscape **局部求解器**（Backward Euler, 1µs）（§19/§23.8）。

#### 代数环：前馈改接实测电压后也必须插 1µs Transport Delay

- **现象**：前馈支路 `实测Vbus → ... → duty → 物理网络 → 测量Vbus` 形成瞬时代数环，编译报 algebraic loop。
- **修复**：前馈输入 `FF_Delay` 与反馈 `Transport Delay` 都插 1µs 延迟破环（§26.15 定式）。这是 Day14 接前馈后新引入的环，漏掉必报错。

### Day15 700V 系统级安全踩坑（计划/方案，移植自 PV_Microgrid_Protection.slx）

> 本天在 Day14 闭环模型上叠加"故障注入 + 过欠压保护链 + 接地/绝缘监测"，形成《直流微电网系统级安全方案》。以下为方案/计划阶段梳理的移植要点与坑（逻辑照搬 48V `PV_Microgrid_Protection.slx`，阈值按 700V 重算）；详见 `Day13到Day14_15升级操作方案.md` §2 与 `计划.md` day15。

#### 阈值必须按 700V 重算（不能搬 48V 的 30A / 33.6V）

- **现象**：直接复制 48V 保护的 30A 过流、33.6V 欠压阈值，700V 系统要么永不动作、要么误动。
- **修复**：欠压 = 70%×700V = **490V**；过流 = **3×I_rated(700V 侧)**（按本系统额定功率/电流算，绝非 30A）。逻辑结构（比较器→OR→锁存→断路器）与 48V 完全一致，可直接搬模板。

#### 保护链照搬 48V 模板，但 Brk 栅极接 Q（非 Qbar）

- **现象**：照搬时 Brk 接了 Qbar，结果断路器从一开始就开路、短路根本注不进。
- **根因**：栅极约定 G>0.5V=开断；锁存器置位后应让 Brk 开断 → 接 **Q**（Qbar 是反相）（§26.9/§23.7）。

#### 投运门：启动 10ms 内封锁 S 端，防软启动误锁存

- **现象**：不设投运门，上电升压途中母线 <490V，比较器立刻锁存、系统"一起步就跳闸"。
- **修复**：`Step`@10ms + `AND` 串在 S 端之前，10ms 内 S 被封死；过了软启动才允许保护动作。

#### 延时确认窗 20~50µs 权衡误动 / 过冲

- **现象**：延时太短，开关纹波/毛刺直接触发误动；太长，故障电流已建立、开断 L·di/dt 过冲变大。
- **修复**：故障检测后加 20~50µs `AND` 确认窗，让故障电流先建立、滤掉瞬态毛刺。

#### 三关验证：A 敏感性 / B 选择性 / C 鲁棒性

- **A 敏感性**：仅注入短路 → 母线跌≈0 后 Brk 开断、恢复≈700V。
- **B 选择性**：仅光照/负载扰动、不短路 → Q 恒 0、Brk 不误动。
- **C 鲁棒性**：扰动+短路同时 → 保护仍抢占跳闸。
- 三关全过才算合格（呼应继电保护"四性"，§21.0）。

#### 开断 L·di/dt 过冲靠 Snubber / 避雷器（非保护逻辑错误）

- **现象**：Brk 切断感性回路时感应 ~125V（约 2.6×48V 量级，700V 下更高）过冲。
- **根因**：法拉第定律 V=L·di/dt，属物理必然，非逻辑 bug。
- **修复**：RC Snubber / 避雷器 / 软开断抑制；保护链本身正确。

### 第一阶段：搭出能跑的物理底座

- **目的**：把"光伏+Boost+蓄电池+负载"这个48V直流微电网在 Simscape 里物理搭通，跑出可信的开环稳态波形。
- **形象描述**：像盖楼先打地基——地基晃，楼再漂亮也会塌。这5天就是给后面所有控制逻辑打地基。
- **解决什么问题**：确立元件参数选型、Boost工作原理、二极管方向、唯一接地规则、求解器/步长选择等"地基"。
- **为什么必须先做**：控制层（PI/下垂）只能调"已经能跑的物理系统"；物理不对，控制再好也是错。这5天是后面所有工作的前提。
- **核心学点**：Simscape物理建模三规（唯一接地 / 物理域vs信号域 / 传感器"电流串、电压并"）、Boost伏秒平衡与二极管方向、求解器ode23t + 步长1e-6（Ts/20）。
- **⟦补充：对应踩坑 / 落地提醒⟧** 对应"物理底座踩坑"整节（唯一接地、域混淆、电流串电压并、二极管方向、Solver Configuration 接地、参数名、崩溃恢复）。零基础先把 Simscape 三规刻进肌肉记忆——地基错，后面所有控制层的努力都可能建立在错误之上。

### 插入双向DC/DC，让电池能量可控

- **目的**：把电池从"直接硬挂母线"改成"经半桥双向Buck-Boost接入"，使电池充/放电方向可主动控制。
- **形象描述**：电池原本像直连水箱的水管，水只能被动流；装双向变换器就像装了台可正反转的水泵，水往哪流、流多少都能主动控。
- **解决什么问题**：电池直挂=被动钳位母线电压，无法调节。要让母线电压可调，电池必须经变换器隔离+受控。
- **为什么必须做**：闭环调压的执行器就是这台双向变换器；没有它，控制器无处下手。同时验证了双向功率流动（充/放电）。
- **核心学点**：半桥双向Buck-Boost两模式（Buck充电 / Boost放电）、占空比定功率流向、**浮地驱动**（上管驱动负极接源极——"上管跟源跑，下管踩实地"）、死区时间防直通。
- **⟦补充：对应踩坑 / 落地提醒⟧** 对应"双向变换器踩坑"（浮地驱动接错→−900V/数千安冲击；死区未加→直通炸管）。高边驱动自举、死区防直通是硬件级保险——仿真里 48V 侥幸通过 ≠ 真实安全，700V 必须≥300ns 死区。

### 加PI电压闭环，母线自动稳48V

- **目的**：在双向变换器上加电压单闭环PI，自动维持母线48V（替代的固定占空比）。
- **形象描述**：像给房间装空调温控——设定26℃，高了制冷低了制热，自动维持。PI就是母线电压的"恒温器"，母线高了少灌、低了多灌。
- **解决什么问题**：开环固定占空比，光照/负载一变母线就飘。闭环让控制器根据误差自动补偿扰动。
- **为什么必须做**：从"开环能跑"到"扰动下能自治"的关键一跃；也是后续下垂控制、系统保护的控制基础。
- **核心学点**：PI三要素（P管"现在"/I管"过去"/D管"未来"，电力电子常用PI不用D）、静差与积分消除、抗积分饱和、Transport Delay破代数环、软启动。本天产出 P=0.02/I=0.002（`PV_Microgrid_Voltage_Closed_Loop`模型实测值，推翻重整定为 P=0.05/I=2.0）。
- **⟦补充：对应踩坑 / 落地提醒⟧** 对应"PI 闭环踩坑"（代数环、数据类型、PID 限幅冲突、SOC 漂移、P 太小超调、软启动极性）。注意：本天产出 `P=0.02/I=0.002` 是**旧结构实测值**，换结构后推翻为 `P=0.05/I=2.0`（见扰动测试与"换结构必须重整定增益"），不要把它当万能默认参数。

### 扰动测试，验证闭环在暂态下撑得住

- **目的**：在闭环上加光照阶跃（1000→500→1000 W/m²）+负载投切（20→10→20Ω），看控制器能否把母线拉回48V，记录波形分析能量流向。
- **形象描述**：像新车上颠簸试车场——平稳路上开着顺不算数，得过了坑洼（光照突降、负载猛加）还不散架、还能回到48V，才算真过关。
- **解决什么问题**：只验证了稳态。控制器好不好，要看扰动下的暂态——恢复时间、最大偏差、电池电流方向是否正确（PV不足放电/PV富余充电）。
- **本次调试额外收获（关键）**：发现并修复了"设定值闭环PID增益太小→母线飘78V"的真根因——本模型母线调压执行器是电池侧变换器，"调到48V"="让PID把duty顶到1(钳位)"，需PID输出≥1；原0.02/0.001给不出，定稿 **P=0.05/I=2.0**，使模型成为**真闭环**而非电池钳位。详见 §12（扰动测试步骤与波形分析）及本文件「扰动测试踩坑」之「三、duty=1钳位根因」「四、换结构必须重整定增益」。
- **核心学点**：暂态响应评价指标（超调/恢复时间/ITAE）、能量流向分析（PV不足放电/PV富余充电）、**duty=1钳位根因 + 换结构须重整定增益**（本次最核心教训）。
- **为什么必须做**：这是控制策略验证的核心证据，报告里"控制有效"的结论全靠这几张扰动波形支撑。过=第二阶段控制部分的主干完成。
- **⟦补充：对应踩坑 / 落地提醒⟧** 对应"扰动测试踩坑"全部 4 条"误判"+真根因+换结构重定增益。本次最核心教训 = `duty=1 钳位根因` + `换结构须重定增益`；定稿 `P=0.05/I=2.0` 使模型成真闭环。任何"数值好看但机理错"的伪修复（翻符号、断 in2、Rate Limiter 软启动、抗饱和）都被排除。

### 下垂控制，让多源并联无需通信自动均流

- **目的**：把的定压PI控制器改成电压下垂控制器——在母线电压参考值上叠加一个与电池电流成比例的偏差项，实现"有意引入电压偏差来换取无通信功率协调"。并在模型中并联第二路电源（受控电流源），验证多源自然均流。
- **形象描述**：像几台水泵并联往同一根总管抽水/注水，彼此不打电话（无通信线），每台只看"自家出口压力比总管低多少"就自动决定抽多少——压力低的多抽，压力高的少抽，自发平分负荷。
- **解决什么问题**：真实微电网里多个储能/分布式电源并联，若靠中央通信分配功率，一旦通信故障全网瘫痪。下垂控制让每个源按本地电压/电流自治，通信断了也能稳。
- **本次调试关键修正（符号陷阱）**：教材写 Vref = V0 − k·Iout，但本项目 Ibat 定义"正=充电、负=放电"，与教材"流出为正"相反，故本项目须写 **Vref = V0 + k·Ibattery**。若照搬减号，电池会在该放电时反而充电，逻辑全反。（注意：前面40天计划仍写 V0 − k·Ibattery，属计划笔误，此处以实际模型为准，未改动计划原文。）
- **核心学点**：下垂控制本质=虚拟电阻（k = 1/Rv）、无互联线功率分配原理、均流比由虚拟电阻反比决定（Rv1:Rv2 = 1:2 ⇒ 源1出力≈源2的2倍）、以及上述电流方向符号陷阱。详见 §10（双源并联下垂控制）与 §21（名词术语解释）；多源协同的上层架构另见 §15（分层控制）。
- **⟦补充：对应踩坑 / 落地提醒⟧** 对应"下垂控制踩坑"整节：符号陷阱（Vref=V0+k·Ibat）、PID 上限须 1.0、负载未对齐、Vbus2 命名误导、源2 t=0 尖峰用 Saturation3、PID 三问题修复（P=0.1/I=50）。均流比由虚拟电阻反比决定，是下垂的定量判据。

### 极间短路故障仿真，验证直流故障的"不可控"本质（✅ 已完成，2026-07-25）

- **目的**：在双源并联模型上，于母线正负极间经`Rf=0.1Ω`注入一次**极间短路**（t=0.045s 闭合理想半导体开关），录波`Vbus`/`Ibat`/`Isrc2`观察短路瞬态并量化故障电流峰值，验证 §14 理论。
- **形象描述**：像给已经能稳48V的配电系统人为拉一根"火线碰零线"——看保护没上之前，母线会被瞬间抽垮到什么程度、电流会飙多猛。
- **解决什么问题**：前10天都假设"系统永远健康"，没验证最危险的故障工况。本天用仿真把"直流短路到底多可怕"量化出来，为设计保护逻辑提供**必须快速开断**的硬证据。
- **本次实测关键反转**：原以为 ±10A 限幅（`Saturation3`）能压住故障电流，实测`Ibat_peak`≈2400A、`Isrc2`被牢牢限在10A——证明**控制器限幅只管源侧控制通道，跨母线并联短路的故障电流绕过限幅由电容放电+电池灌入**，限幅救不了短路。母线从 ~47.8V 骤降到 ~0V、末段被 Rf 钳位到 ~28V（<70%额定欠压阈值）。
- **核心学点**：直流短路**无自然过零点 / di/dt 极高 / 故障电流主由电压源提供**；常规交流断路器不能用于直流，须 μs 级固态/混合直流断路器；"控制器主动限流"只能管源侧过载，不能替代快速开断。详见 §14（已回填实测）与本文件「极间短路仿真踩坑」。

### 过流+欠压保护，给系统上“故障保险”（✅ 已完成，2026-07-26）

- **目的**：前11天只证明“故障多可怕”，本天给系统加**保护逻辑**（比较器+SR锁存器），让它在极间短路时**自动检测并可靠跳闸隔离**，把 的灾难性跌落变成“短暂扰动后恢复”。
- **形象描述**： 是“拉了火线碰零线却没人拉闸”，是“装了漏电/过流保护器，一短路就啪地跳闸”。
- **解决什么问题**：没有保护的直流系统一旦短路，母线被钳在 ~28V(<70%额定)、电流飙到 kA 级，器件秒毁。保护把“故障→隔离”的时间压缩到微秒级，系统可自恢复。
- **本次实测关键反转**：① Brk 栅极约定 G>0.5V=开断，必须接 SR 锁存器 **Q**（接 Qbar 会让 Brk 从一开始就开路、短路注不进）；② 锁存器 R 接地无复位，不加 10ms 投运门会在启动升压途中(<33.6V)误锁存；③ 加 20~50µs 延时确认窗让故障电流先建立。三测试 A/B/C 全过。
- **核心学点**：SR 锁存器用“S=故障、R=0”实现**一次性自锁**(跳闸后不抖合)；接地方式(IT/TN-S)与绝缘监测是直流安全方案骨架；开断感性回路会产生 L·di/dt 过冲(本仿真~125V)，需 RC 缓冲/避雷器抑制。详见 §14 印证、§20 触发器基础、本文件「极间短路保护踩坑」。
- **最终产出**：`PV_Microgrid_Protection.slx`(保护逻辑模型)、`Day12_保护逻辑搭建方案.md``Day12_修正备忘.md`；源文件`PV_Microgrid_shortcircuit.slx`未动，保护为 新建工作副本。
- **⟦补充：对应踩坑 / 落地提醒⟧** 对应"极间短路保护踩坑"整节：Brk 接 Q（非常 Qbar）、检测链完整 + Ibat 过 Abs 取绝对值、启动投运门防误锁存、开断 L·di/dt 过冲靠 Snubber、验证顺序 A/B/C。SR 锁存器的"记忆上次指令"特性决定了必须配投运窗/复位，否则上电即误锁。

### 升级 700V + 隔离 DAB，把学习平台变成"工程级架构"（✅ 已完成，2026-07-26）

- **目的**：前12天是 48V 学习平台；课题要的是"高效直流配电架构"，需要更高电压等级。本天把母线升到 700V，并让电池经**隔离型双向 DC/DC（DAB）**接入——既满足高压安全隔离，又为后续双向功率调度打底。
- **形象描述**： 是"给 48V 小院装漏电保护"，是"把小院接入 700V 市政高压，中间必须加隔离变压器才安全"。
- **解决什么问题**：48V 系统电池非隔离可行（同地低压）；升 700V 后高压窜入电池/人员可触电路的风险不可接受，且多了一个隔离变压器，拓扑从"非隔离 Buck-Boost"变成"双全桥+变压器+漏感"。
- **核心学点**：DAB 用**移相角 φ**一个旋钮同时管功率大小与方向（公式 $P\propto\phi(\pi-\phi)$）；靠变压器漏感实现 **ZVS 软开关**，死区≥300ns 是前提；电压匹配时 ZVS 最易、轻载会丢 ZVS；隔离的必要性（安全/地环路/共模噪声）。详见`Day13_700V隔离DAB搭建教程与原理报告.md`§13。
- **最终产出**：`PV_Microgrid_Day13_700V.slx`（700V 开环模型）、`Day13_700V隔离DAB搭建教程与原理报告.md`；再移植 PI/下垂做闭环。
- **⟦补充：对应踩坑 / 落地提醒⟧** 对应"700V 隔离 DAB 开环模型踩坑"整节：拓扑从非隔离变双全桥+变压器+漏感，必须新建（红线）；DAB 漏感=功率媒介（公式 $P=\frac{nV_1V_2f_{sw}}{L}\phi(1-2\phi)$）；死区≥300ns=ZVS 前提；匝比≈V1/V2（本项目原:副 700V:240V≈2.92:1，即 $n=240/700$；早期误用 15:1）；Boost 升压比≈1.6 倍（Vmp≈432V→700V，D≈0.383；早期误设想 28 倍/D≈0.964）；隔离两边地须分开；开环不指望精确稳压。

### 错误 E4：~~`Solver Configuration` 的 DoDC（启动稳态）原 OFF → 应改 ON~~ → **【2026-08-07 撤稿并反转】必须保持 OFF**

> **本条建议已作废，且方向相反。** 2026-08-06 建议把 `DoDC` 由 `off` 改 `on` 是**错的**，它是后续"母线 0 V 启动 + DAB 无控预充 + 漏感 149 A 冲击"的**直接根因**。

- **位置**：`PV_Microgrid_700V_/Solver Configuration`（⚠ **该模块名里含换行符**，见下方"排查陷阱"）
- **正确设置**：`Start at steady state (DoDC) = **off**`
- **机理**：`DoDC=on` 让 Simscape 先解一个**直流稳态工作点**再起跑，这个工作点会**无条件覆盖所有电容的初始电压**（`C_bus.vc=700`、`Cin_Bat.vc=240`、`Cin_PV.vc=430` 全部作废）。而 t=0 时刻所有开关都是关断的，母线上只挂着 `R_Load`，稳态解自然是 **0 V**。于是：
  - 母线从 0 V 起跑 → DAB 副边桥体二极管把电池能量整流灌入母线（**无控预充**）→ 漏感冲击电流 149 A → `OC_Bat` 跳闸。
  - 手册 L778 明确要求"所有电容预充 `vc_specify=on`"，`DoDC=on` 与该要求**直接冲突**。
- **实测对比**（副本，5 ms）：

  | DoDC | `V_bus(t=0)` | `V_pv(t=0)` | 结果 |
  |---|---|---|---|
  | `on` | **0.000 V** | — | 母线 0→8→24→39→68→98→134 V 无控爬升 |
  | `off` | **700.076 V** | 430.08 V | 预充生效 ✅ |

- **副作用（可接受）**：`DoDC=off` 时 Simscape 会报 *"First solve for initial conditions failed to converge / 无法满足所有初始条件 (RCOND=5e-23)"*，列出 `C_*.vc`、`L_*.i_L`、`S1–S8.v_Cds` 冲突。这是**非致命告警**，仿真照常跑完且预充值正确（模型同时存在 legacy `vc_*` 与新版 `v_*` 两套初值字段，必然互相冲突）。
- **两个排查陷阱（务必记住）**：
  1. **`Solver Configuration` 的模块名里含换行符**（XML 里是 `&#xA;`）。`contains(nm,'Solver Configuration')` 和 `strcmp` 都**匹配不到**，`set_param(...,'DoDC','off')` 会**静默跳过**——之前 `test_dodc_off.m` 就是这样"改了但没改成"。必须先展平：`flat = regexprep(nm,'\s+',' ')` 再 `contains`。`AND_A` 模块名同样含换行。
  2. **不是电容 `v_priority` 的问题**（`test_vprio.m` 把所有电容设成 `High` 后结果逐位相同），**也不是求解器的问题**（`test_solver.m` 换成变步长 `daessc` 结果逐位相同）。唯一变量就是 `DoDC`。

### 错误 E5：S4 第二路储能电流源闭环构成代数环（编译即报错）
- **位置**：`Sat_src2 → Simulink-PS Converter8 → Source2_CCS`（电流源）→ 网络 → 传感器 → `Err_Src2 → G_src2 → Sat_src2`
- **现状**：反馈环无任何延时，且 `Solver Configuration`（Simscape 局部求解器）落在代数环内 → 编译报错 *"Solver Configuration … 在代数环中不受支持"*。
- **应改为**：在 `Sat_src2` 输出与 `Simulink-PS Converter8` 输入之间插入 `Transport Delay`（Delay=1e-6，与手册 TD_* 一致），副本命名为 `TD_src2`。
- **影响**：不破除则模型**根本无法编译运行**。

### 错误 E6：S5 保护路径数据类型不匹配（boolean ↔ double）
- **位置**：`DTC_Trip(boolean) → TD_Confirm(Transport Delay，只收 double) → Latch(CombinatorialLogic，只收 boolean)`
- **现状**：类型不匹配会让 TD_Confirm/Latch 报错。

### 错误 E10（**DAB 第二阻断项，2026-08-07 新增**）：相移量 `φ_pu` 未做逐周期采样保持（缺 ZOH）

> 修完 E9 之后 `I_Lk` 仍有 **+144 A 直流偏置**、`φ_pu` 依然贴 ±0.2、母线塌到 606 V。根因是**调制器缺一个零阶保持**，不是 PI 增益问题。

- **机理**：`PI_DAB` 是**连续时间** PID（`TimeDomain=Continuous-time, SampleTime=−1`），输出 `φ_pu` 每个求解步都在变。而副边载波是 `c2 = mod(c1 − φ_pu, 1)`——**φ 一动，c2 就整体跳变**，于是在同一个载波周期内 `c2` 会**反复穿越**比较阈值（0.01 / 0.5 / 0.51），产生大量多余开关沿。
- **实测铁证**（4.50 ms 处单个 50 µs 载波周期，1 µs 采样）：

  | 区间 t[µs] | 0–12 | 13–29 | 30–32 | 33–35 | 36–49 |
  |---|---|---|---|---|---|
  | `V_sec` | −663 | **+666** | −663 | **+668** | −664 |

  一个周期里 **6 次翻转**（正常只应 2 次），正电平只占 **40.5%**、负电平 **59.5%** ⇒ `mean(V_sec) = −124 V` 的巨大直流伏秒 ⇒ 理想变压器无隔直能力 ⇒ 漏感直流电流 = ΔV/R ≈ **144 A**。
- **另一条判据**：`V_pri − n·V_sec ≡ 0.000 V`（n=240/700）在所有时间窗都精确成立 —— 说明 `V_pri`/`V_sec` 两个探头量的是**理想变压器两侧**（V1≡n·V2 是恒等式），**不是桥中点**，所以直流偏置只能来自副边桥的多余开关沿。（后续排查别再拿这两个通道去算漏感压降。）
- **应改为**：在 `PI_DAB` 输出与 `Shift` 的 `−` 输入之间**插入一个 Zero-Order Hold，采样时间 = 载波周期 `50e-6`**（即 20 kHz，与 `Carrier_Pri` 的 `rep_seq_t=[0 50e-6]` 对齐，t=0 起同步）。
  - 脚本实现：`s4check/fix_zoh.m`（自动定位 `PI_DAB` 送入 `Shift` 的是第 2 个入端口，`delete_line` 后 `add_block('simulink/Discrete/Zero-Order Hold', …, 'SampleTime','50e-6')` 再 `add_line` 两段）。
  - 等效替代：把 `PI_DAB` 掩膜参数改成 `TimeDomain='Discrete-time'` + `SampleTime='50e-6'`（本质相同，未采用是为了不动手册规定的 PI 结构）。
- **效果（副本实测，5 ms，保护关）**：

  | 指标 | 仅修 E9 | **+ E10 (ZOH)** | 判据 |
  |---|---|---|---|
  | 每周期开关沿 | 6 | **2.00** | =2 ✅ |
  | `V_sec` 占空比 | +0.405/−0.595 | **+0.507/−0.493** | ≈0.5 ✅ |
  | `mean(V_sec)` | −124 V | **+10.5 V** | ≈0 ✅ |
  | `V_bus`[4–5 ms] | 665（最低 606） | **701.79 V** | 700±7 ✅ **D1 达标** |
  | `φ_pu`[4–5 ms] | 0.135（贴 ±0.2） | **0.0086**（−0.031~0.052） | 不贴限幅 ✅ |
  | `I_Lk` 直流 | 144.4 A | **41.5 A** | 仍偏（见 E11） |

- **影响**：这是继 E9 之后**让母线真正能稳到 700 V 的关键修复**；不修则 `φ_pu` 永远饱和、母线永远塌。

### 错误 E11（**仿真设置项，2026-08-07 新增**）：定步长 1 µs 无法解析 0.5 µs 死区 → 占空比量化抖动

- **机理**：手册死区取载波的 1%（比较阈值 `>0.01` / `<0.5` / `>0.51`），在 20 kHz（T=50 µs）下 = **0.5 µs**；而模型 `FixedStep = 1e-6`（1 µs）。**死区窗口比一个时间步还窄**，落到网格上时有时无：

  1. **细化定步长**（物理正确、代价是慢 10 倍）：`FixedStep = 1e-7`，死区 0.5 µs = 5 个步长，可完整解析。脚本 `s4check/fine_step.m`。
  2. **加宽死区到 ≥2 个步长**（保持 1 µs 步长、仿真快，但偏离手册 1% 死区）：比较阈值改成 `>0.04` / `<0.48` / `>0.52`（死区 4% = 2 µs = 2 步）。

## 6. 修改原因（Why）

1. **S2PS 滤波 0.001 vs 1e-9** —— 手册 S0-2(c) 明确写 `Input filtering time constant | 1e-9（别留 0.001）`；手册第九节报错对照表也列：`门极波形发钝、开关沿不清晰 | Simulink-PS Converter 滤波常数 0.001 | 改成 1e-9`。开关周期 50 µs，1e-9 是无相移的"直通"，0.001 是 1 ms 一阶滞后（时间常数 = 20 个开关周期），门极沿被严重展宽。当前虽因 `FilteringAndDerivatives=zero` 而惰性，但**手册点名的硬伤，必须改**，且若日后切换滤波模式将立即破坏保护速动性（特别是 S2PS_Brk）。
2. **S2PS_Brk 延迟破坏保护速动性** —— 手册 S5-F1 要求短路后 30–50 µs 内 `Latch(Q)=1`、`Brk` 开断。1 ms 滤波让断路器门极滞后 1 ms（≈20–33 倍），保护实质失效。
3. **`GD_Boost.uHighValue=12`（致命根因）** —— 门驱"输入逻辑阈值"应远低于驱动电平，模型其余门驱统一 0.7；此处误填为 12，恰等于 G12_Boost×12 的输出电平，浮点下 `12 > 12` 为假，**Q_Boost 永不导通**，系统无法升压。证据：原图 2 ms 跑 `Vpv` 双极性 ±567/−371 V、`I_L_Boost` 峰值 161 A（≈自由谐振 Voc·√(C/L)=153 A）；修复后 3 ms 跑 `Vpv` 单调 567→280、`I_L_Boost` 真实 PWM 纹波 24 A（CCM→DCM 边界），Q_Boost 正确开关。
4. **`GD_Boost.vHigh=15→12`** —— 手册 L415 明确指定 12 V；15 V 仍可驱动 Vth=3 V 的 Q_Boost，非阻断，但应手册对齐。
5. ~~**Boost 短路**~~ —— **已撤稿**（见 §5-B），接线经 XML 网表证伪正确。

### 10.2 残留问题：Buck 环 5 kHz 振荡（V_out D3 失败）

- **现象**：`V_out` 在 90–100 ms 内 pkpk=177 V（316–494 V），远高于 D3 的 ±4 V 容差。振荡主频约 **5 kHz**（肉眼读 `long100_wave.png`），是开关频率 20 kHz 的 1/4，可能为次谐波振荡。
- **根因（已定位）**：手册 `PI_Buck P=1.5e-3 / I=3`（`MaskType=PID 1dof`, `IntegratorMethod=Forward Euler`, `SampleTime=−1`）。**`I=3` 过大**：前向欧拉法在 1 µs 步长下被误差信号推动时积分增量 = `3·err·1e-6`，碰到 V_bus 谐波那种突变瞬间饱和到 0.95 / 0.05，输出占空比在每个开关周期都被反复推到饱和。
- **与 Boost 环类比**：Boost 也是用 `I=0.5`（手册）→ 0.1 才稳；Buck 完全没降级。

### 10.4 Buck 环重定（偏离手册但必要）—— 已列入必修错误 E12

- **位置**：`PV_Microgrid_700V_/PI_Buck`
- **现状（手册）**：`P=1.5e-3, I=3, LimitOutput=on, UpperSaturationLimit=0.95, LowerSaturationLimit=0.05, TimeDomain=Continuous-time, IntegratorMethod=Forward Euler`
- **应改为**：`I=0.3`（P 不变，限幅、积分方法不变）
- **影响**：Buck 输出 V_out 从 5 kHz 振荡（pkpk 177 V）→ 衰减到 ±15 V 量级（pkpk 32.6 V）；`V_out` 偏离 400 V 仅 0.36 V。**这是 DAB 修复后唯一剩余的非 DAB 阻断项**；不修则 D3 判据 fail。
- **机理**：仿真侧 Buck 拓扑 L_Buck=0.5 mH / C_Buck=100 µF（f_res≈712 Hz），电压环穿越频率天然在 1 kHz 附近；手册 `I=3` 把积分零点推到 DC、Forward Euler 1 µs 步长下 `I·Ts=3e-6` 太大，叠加 PWM 半个周期延迟（25 µs → 90° 相位滞后）→ 在 5 kHz 处相位裕度跌穿 0° → 次谐波振荡。降 I 后相位裕度恢复到 60° 以上。
- **与 Boost 环/E11 排查的同一思路**：手册 PI 参数在仿真（特别是 1 µs 定步长 + Forward Euler）下普遍偏激，**两环降级（Boost I→0.1、Buck I→0.3）已构成仿真侧的标准修复**。

### §10.10 Rate Limiter 限 φ 变化率 — 验证与结论

#### 背景
§10.9 已确认 C_block(100µF) 消除了稳态直流偏置，但 DAB 工作点阶跃（~26ms、60–68ms）产生的暂态直流偏置 ~24A 仍触发 OC_Bat(20A) 在 68ms 锁存。为此在 `PI_DAB→ZOH_phi` 之间插入 Rate Limiter（`RL_phi`），限制 φ 变化率使电容跟得上暂态。

#### 失败尝试 1：IC=0 导致启动过压
- 初版 `insert_rl.m` 将 `RL_phi.InitialCondition='0'`，导致 φ 从 0 起步（稳态约 0.01）→ DAB 在 15ms 使能瞬间相移≈0、不传功率 → 母线被 Boost 灌到 **1399V** → 投运即锁存。
- 修正 `IC=0.01` 后重扫，**slew=0.5 仍 Vbus=1399.66V**（与 IC=0 逐位相同）→ **根因不是初值**，而是 **RL 把 φ 变化率卡死**，无论 IC 取何值，slew 过小都无法让 DAB 在启动时快速建立相移。

#### 失败尝试 2：slew 过小导致启动锁存
- 25ms 短诊断 `diag_rl.m`（保护投运 0.015）确认：slew=100/20 启动不过压、LatchQ=0 @25ms；slew=10 在 15.81ms 锁存。**启动动态阈值在 slew≈10–20 之间**。
- 但 25ms 诊断**太短**，无法看到 30ms 之后的锁存。

#### 关键发现：结构性矛盾
- 无 RL + C_block：LatchQ 在 **68ms** 锁存（DAB 工作点阶跃暂态偏置 24A > 20A）
- 有 RL(slew=15/20) + C_block：LatchQ 在 **30.43–30.53ms** 锁存（RL 限慢 φ → 启动暂态过流被推迟但未消除）
- **RL 消除了 68ms 暂态偏置（ILk_60-80≈0），但引入了更早的 30ms 启动锁存**——单一个 RL 无法同时满足"启动快变"和"暂态慢变"两个矛盾需求。

#### 工程教训
1. **Rate Limiter 的 IC 必须与稳态初值匹配**：IC=0 导致启动 φ=0，DAB 不传功率，母线灌爆。IC=0.01 修复了初值问题，但 slew 过小仍是致命的。

4. **C_block + RL 组合是必要且充分的**：C_block 消除稳态直流偏置，RL 抑制暂态 φ 跳变。缺一不可。

### 13.1 各反馈回路"调什么、基于什么调"

### 13.2 出现什么情况 → 调哪个反馈 → 为什么

**🔴 大电流 / 过流跳闸（最关心）**
- **DAB 漏感直流偏置大电流（稳态可达 ~144A，触发 OC_Bat）** → 先查 **ZOH_phi(50µs) 是否就位 + C_block=100µF 是否串入**，不是动 PID → 因为连续 φ 逐周期变会让副边载波每周期穿越 6 次开关沿，V_sec 占空比不对称（40.5/59.5），mean(V_sec)=−124V，漏感被灌入直流偏置；ZOH_phi 固定 φ 命令、C_block 隔直后 I_Lk 才零中心（见 E10、§10.9）。
- **启动 / 负载阶跃暂态电池过流（LatchQ=1）** → 调 **RL_phi 的 slew 减小（当前 30）** → 因为 DAB 工作点变化率过快→暂态伏秒失衡→漏感直流偏置→电池过流；限制 φ 变化率即抑制（§10.10）。
- **Boost 输入 LC 谐振大电流（I_L_Boost 触零 / 峰值异常）** → 调 **PI_Boost 的 I 减小** → 因为 3mH/220µF 输入 LC 谐振点 ~196Hz，PI_Boost 的 I 偏大（试过 0.25/0.5）会令 ~250Hz 限环、电流触零；**降 I 是标准修复**。
- **GD_Boost 阈值错导致 LC 自由谐振（I_L_Boost 峰值 161A）** → 这不是 PID 问题，调 **GD_Boost.uHigh=0.7 / vHigh=12**（E7） → 因为阈值恰等于门驱输出电平，`12>12` 为假→Q_Boost 永不导通→PV 在 Cin_PV/L_Boost/D_Boost 间 LC 自由谐振。

**🟠 电压环异常**
- **V_pv 纹波大 / 过冲、I_L_Boost 触零或限环** → 调 **PI_Boost 的 I 往小调** → 同上，输入 LC 谐振 + 1µs 前向欧拉下手册增益偏激，**降 I 是标准修复**；Boost 是"前馈为主 + PI 微纠"，别指望靠加 I 压纹波。
- **V_out 出现 5kHz 次谐波（pkpk 可达 177V）** → 调 **PI_Buck 的 I 往小调（终态 0.3）** → 因为 1µs 定步长 + Forward Euler 下 I=3 令 PWM 半周期延迟相位裕度穿 0 引发振荡；降 I 即消（E12）。**同一规律：该离散化下手册 PI 偏激，降 I 标准修复。**
- **母线 V_bus 略超 ±7（约 705–712V，D1 临界）** → 微调 **PI_DAB 比例增益略增** → 因为母线电压环在临界轨迹上有微小稳态误差；但比例增大会有**复振风险，确认需求后再动**，必要时配合减小 PI_DAB 的 I 防振荡（§11.3）。

**🟡 控制量 / 饱和 / 启动**
- **PID 输出长期顶在限幅边界（duty 到不了 1，母线欠调稳在 78V）** → 调 **对应 PID 的 P/I 整体增大**（如闭环 Boost P→0.05/I→2.0；下垂上限改回 1.0） → 因为本项目执行器"调到目标值"= duty 顶到 1 饱和点，增益不足则控制量永远到不了 1→母线卡中间值；**先调 P 后调 I**（§9 真根因）。
- **启动首峰极高（物理冲击超调）或持续振荡** → 不要硬加 PI 增益，而是 **Ramp Vref 软启动 + 先调 P 后调 I** → 因为电力电子启动有光伏满功率涌入电容的物理冲击，P 太小压不住（与"P 大超调大"直觉相反）；根本靠软启动吸收冲击（§9.2）。
- **积分饱和死区（PI 输出锁死在 0 / 下限）** → ① 误差极性用 `Vbus−Vref`（正确负反馈）② 积分初值给合理中间值（如 0.5）③ 软启动对齐初始状态 → 因为负误差把 PI 推至限幅边界锁死，系统进入不可控饱和死区（§9.1）。
- **换闭环结构 / 加软启动 / 改反馈极性后母线异常** → **重新整定整套 PID** → 因为 PID 增益长在具体控制结构之上，换结构后传递函数变，旧值（如 0.02/0.001）不再适用；先搞清执行器目标工作点再定 P/I 量级（§9.3）。

### 13.3 通用原则（每次调参前先看）
1. **离散化陷阱**：本项目用 1µs 定步长 + Forward Euler，手册级 PI 增益普遍偏激——**"降 I" 是最常用也最安全的修复**，PI_Boost(0.1)、PI_Buck(0.3) 都是这么来的。
2. **调参顺序**：先 P 后 I；一次只改一个环节，逐步验证（§9.3）。
3. **结构一变，增益重定**：加软启动 / 改极性 / 增扰动源 / 换负载，都必须重新审视 PID 适应性（§9.3、§9 四）。
4. **Boost 别硬扛**：700V 的 Boost 是前馈 0.383 + 小闭环微纠，V_pv 的大动态靠前馈和输入 LC 设计，不是靠加 PI 增益。
5. **大电流先分源**：过流先判断来源（DAB 直流偏置 / 暂态伏秒失衡 / Boost 谐振 / 门驱阈值 bug），再决定动 ZOH_phi·C_block·RL_phi 还是 PI——多数"大电流"根本不是 PID 增益问题。

## 14. 各元器件参数来源与选型推导（"怎么来的"）

> 目的：把模型里每个关键元器件的**数值是怎么算出来的**写清楚，下次换工况（不同功率/电压/光照）能自己重算，而不是照抄一个数。以 700V 集成模型终态为准，公式与物理依据来自 §1.1 单二极管模型、§2.1 Boost 设计、§20/§22 元器件库、§10.9 C_block 推导。

### 14.1 光伏板（PV Panel）—— 你最关心的例子
- **"1000" 是哪来的**：`G_STC = 1000 W/m²` 是光伏**标准测试条件（STC）**的标况辐照度（配 T_ref=25℃、AM1.5 光谱），所有光伏数据手册的 Isc/Voc/Pmax 标称值都在这个条件下给出。模型里改 `Ir`（辐照度）就是平移 I–V 曲线，所以"正常光照 = 1000"。
- **短路电流 Isc 怎么算**：
  - **光照缩放（主因）**：`Isc(G) = Isc_ref × (G / G_ref)`，G_ref=1000。光照减半 Isc 减半——Simscape `Solar Cell` 对辐照度就只做这一条线性缩放。
  - **温度修正（很小）**：`Isc(G,T) ≈ Isc_ref·(G/1000) + α_Isc·(T − T_ref)`，α_Isc≈**+0.05%/℃**（正温度系数，硅电池 Isc 随温度略升）。
  - 本项目标况 `Isc_ref = 8.5 A`（单板 60 串）。
- **开路电压 Voc 怎么算**：
  - **光照影响小**：`Voc(G) = Voc_ref + β_Voc·ln(G/1000)`，β_Voc≈−0.1~−0.2 V/十倍照度（因为 Voc∝lnG）。
  - **温度影响明显（负温系）**：`Voc(G,T) ≈ Voc_ref + β_Voc·ln(G/1000) + γ_Voc·(T − T_ref)`，γ_Voc≈**−2~−2.5 mV/℃/cell**（硅电池 Voc 随升温下降）。
  - 本项目 `Voc_ref = 37.8 V`（60 串 → `V_array = Ns·V_cell`，单晶每片 ≈0.63V）。
- **最大功率点 MPP**：`Vmpp ≈ 0.76·Voc`（分数开路电压法，极简）；`P_max = Voc·Isc·FF`，FF（填充因子）≈0.7~0.85 衡量曲线"方不方"。
- **串并联怎么定电压**：`Ns` 串 → 电压相加、电流不变；`Np` 并 → 电流相加、电压不变。本项目 432V 母线需约 **11 块 37.8V 板串联**（≈430/37.8）才能把光伏侧抬到 Vmp≈432V。

### 14.2 Boost 电感 L_Boost = 3mH
- **来自 CCM 临界电感**：`L_crit = (1−D)²·R_load / (2·f_sw)`；选值须 **≫ L_crit** 才进深 CCM（电流连续、纹波小）。
- **D 怎么来**：由伏秒平衡 `V_out = V_in/(1−D)`，432V→700V 得 `D≈0.383`（占空比适中、余量足；早期误按 25V 输入得 D≈0.964 是隐患）。
- 本项目 L_Boost=3mH 留约 **20× 裕量**（深 CCM、极稳，适合教学/验证平台；代价是电感偏大、体积重）。

### 14.3 各电容（容量怎么定）
- **Cin_PV = 220µF / 430V**：吸收 Boost 开关纹波、稳定光伏侧电压，按纹波容差 `ΔV = I_L·D/(C·f_sw)` 定。
- **C_bus = 470µF / 700V（母线支撑）**：平滑 Boost 输出 + 缓冲负载瞬变 + 上电"预充电"消浪涌；hold-up 按 `ΔV = I·Δt/C` 定。
- **C_Buck = 100µF、Cin_Bat = 470µF / 240V**：输出/电池侧滤波同理（Cin_Bat 初始电压随版本变：双向/闭环=48V、扰动/下垂/短路=24V、700V DAB 副边=240V，见 §22.2）。
- **C_block = 100µF（DAB 漏感串联隔直）**：`Xc(20kHz)=1/(2π·2e4·1e-4)=0.08Ω ≪ X_L=4.4Ω`（对开关频率透明）；`f_res=1/(2π√(35µH·100µF))≈2.7kHz`（低于开关频率，安全）；稳态 `V_bat=240≈n·V_bus` 故电容稳态压降≈0、仅暂态充放（§10.9）。

### 14.4 DAB（隔离双向）—— 匝比与漏感怎么定
- **匝比 n = 240/700 ≈ 0.343（原边:副边 = 700V:240V ≈ 2.92:1）**：按额定 `V1 ≈ n·V2` 设计，使额定工作点功率能力最大；失配（早期误用 15:1 按 48V 副边）会缩 ZVS 范围、增回流功率（§20 匝比坑）。
- **漏感 Lk = 35µH**：既是功率传输媒介又是 ZVS 来源；传输功率 `P ∝ V1·V2/(f_sw·Lk)·φ(π−φ)`（φ 为移相角，归一化到开关半周期 [0,π]），**Lk 按额定功率在 φ 最大处留出余量选型**——Lk 太小则额定功率需接近满移相（失控余量小），太大则轻载时 φ 极小、难控。
- **移相角 φ**：DAB 一个旋钮管功率大小与方向（φ>0 原边超前=电池充电，φ<0 反向放电）。

### 14.5 电池（OCV 与 SOC 怎么来）
- **开路电压 OCV ∝ SOC**：本项目 700V 集成电池 `OCV ≈ Vnom·SOC`（Vnom=700V，容量 50Ah）→ SOC=100% 时 OCV≈700V，母线才正常建压（§4 早期卡点：SOC=50%→OCV≈350V 母线起不来）；DAB 副边电池侧额定 240V，avg 模型用 `V_bat = 200 + 80·SOC`（SOC=0.5→240V）。
- **SOC 怎么积分**：`SOC[k] = SOC[k-1] − I·Δt / Qnom`（Qnom 为安时容量，零偏会在积分中线性累积漂移，LFP 中段 OCV 近乎平顶难以反推校正，见 §4 SOC 漂移坑）。

### 14.6 保护阈值（怎么定的，不是拍脑袋）
| 阈值 | 取值 | 怎么来 |
|---|---|---|
| UV_Bus | < 490V | **70% × 700V**（欠压，防深度掉压） |
| OV_Bus | > 805V | **115% × 700V**（过压） |
| OC_Bus | > 43A | **3 × I_rated(700V 侧)**（I_rated≈14.3A @ ~10kW；3 倍躲过正常峰值、卡住故障） |
| OC_Bat | > 20A | **3 × I_rated(240V 电池侧)** |
> 原则：电压阈值按母线额定 % 取，电流阈值按额定 **3 倍**（绝非照搬 48V 的 30A）；逻辑结构 检测→确认(TD_Confirm=30µs)→锁存(SR)→执行(Brk) 与 48V 完全一致（§20/§22.7）。

### 14.7 开关频率 / 采样 / 投运门 / 门驱（系统级参数）
- **f_sw = 50kHz**（Boost/DAB 统一）：L/C 纹波、DAB 功率能力都按它算；越高纹波小但开关损耗大。
- **采样 1µs（= 开关周期 1/10~1/20）**：避开开关频率及其整数分频，防"同频锁相"把开关纹波均值污染成虚假直流偏置（采样定理坑，§9.1）。
- **Enable_Gate = 15ms（投运门）**：上电软启动 15ms 内不判故障，防启动冲击误锁存（延到 50ms 也躲不过暂态过流，§10/§22.7 PRT）。
- **GD_Boost.uHigh=0.7 / vHigh=12（E7 修复）**：门驱阈值须**小于** G12×12 的输出电平，否则 `12>12` 为假→Q_Boost 永不导通→PV 在 Cin_PV/L_Boost/D_Boost 间 LC 自由谐振（I_L_Boost 峰值 161A）。

## 15. 各已完成模型的参数来源说明（"每个模型怎么来的"）

> 通用公式与物理依据见 §14（光伏 Isc/Voc、Boost L_crit、电容纹波、DAB 匝比/漏感、电池 OCV/SOC、保护 % 阈值、f_sw/采样/投运门）。本节对**工作区里每一个已定稿的 `.slx` 模型**逐一列出其关键参数取值与来源，避免"换模型就忘了这组数为什么"。
> 电压等级分两类：**48V 系统**（基础/双向/闭环/扰动/下垂/保护/短路）与 **700V 集成**（含平均模型）。元件基础值（48V 通用）见 `笔记.md` §22.2 表格，本节只补"怎么来的"与版本差异。

### 15.1 PV_Microgrid.slx — 基础开环（48V，起点）
- **定位**：最原始验证平台，无闭环、无保护；唯一目的是跑通"PV→Boost→母线→负载"拓扑。
- **辐照度 Ir = 1000**（`Constant=1000`）：STC 标况，含义见 §14.1。
- **Boost 固定占空比 50%**：开环验证，未做 MPPT/调压（§1.2、§22.2 注）；输入≈24V、输出≈48V 由 D≈0.5 的近似关系摆出。
- **L_Boost=500µH(0.05Ω) / Cin_PV=100µF(0V) / Cin_Bat=100µF(48V) / Cout_Bus=500µF(48V)**：48V 系统通用元件，来源见 §14.2/§14.3（L_crit 留 20× 裕量进深 CCM；电容按纹波/hold-up）。
- 无 PI、无 Saturation、无保护逻辑——这是它和后续所有版本的最本质区别。

### 15.2 PV_Microgrid_Bidirectional.slx — 双向（48V）
- **定位**：在基础开环上加储能双向变换器，电池可充可放。
- **Ir = 500（`Constant=500`）**：半辐照工况演示；**门驱电压 = 12（`Constant1=12`）**：MOSFET 驱动电平（同 §14.7 的 G12×12）。
- **L_bidir = 500µH**（BAT-3，§22.2）：双向功率传输核心，与 Boost 同量级。
- **Cin_Bat = 100µF / 初始 48V**（双向版初值 48V，§22.2 BAT-2）：电池侧滤波，初值取电池额定。
- 其余同基础开环（L_Boost 500µH 等）；仍无固定 PI（双向靠占空比调制方向）。

### 15.3 PV_Microgrid_Voltage_Closed_Loop.slx — 电压闭环（48V，早期）
- **定位**：第一次把母线电压闭环——教训最多的一版（§9 系列坑源）。
- **PID(P=0.02, I=0.002)**：这是"增益偏小"的反面教材——在 1µs+前向欧拉下 P 太小压不住、I 太小积分慢→母线卡 78V（duty 到不了 1），详见 §13.2"PID 输出顶在限幅边界"。**调大的方向**见 §9/§13。
- **Ir=500 / 门驱=12 / Vref=48（`Constant=500/12`、`Vref=48`）**：Vref=48 即母线额定，闭环目标值。
- 元件同 48V 通用（L_Boost 500µH、Cin_PV 100µF/0V、Cin_Bat 100µF/48V、Cout_Bus 500µF/48V）。

### 15.4 PV_Microgrid_Disturbance.slx — 扰动（48V）
- **定位**：在电压闭环基础上加负载/源扰动，验证鲁棒性。
- **PID(P=0.05, I=2)**：相对早期闭环已调大（P 0.02→0.05、I 0.002→2），是把"增益偏激"往可用区推的中间态（终态闭环 Boost 见 700V 的 PI_Boost）。
- **门驱=12（`Constant1=12`）**；**Cin_Bat 初始 = 24V**（扰动版初值 24V，§22.2 BAT-2）——注意与双向/闭环版的 48V 不同，换版本时初值易错。
- 其余 48V 通用元件。

### 15.5 PV_Microgrid_Droop.slx — 下垂（48V）
- **定位**：电池用下垂控制参与母线电压支撑（`Vref = Vnom − k·I_bat`）。
- **下垂 PID(P=0.1, I=50)**：这是**可用**的下垂环增益（P=0.1 给快速响应、I=50 消除静差）；与 §13/§14 记载一致。
- **Saturation3 = ±10A（SID 176）**：电池电流硬限幅，防过充过放——这是下垂版特有、700V 集成里由 OC_Bat 保护替代。
- **Cin_Bat 初始 = 24V**（下垂版，§22.2）；其余 48V 通用。

### 15.6 PV_Microgrid_Protection.slx — 保护（48V）
- **定位**：在闭环/下垂上叠加系统级保护链（检测→确认→锁存→执行）。
- **PID(P=0.1, I=50)**：同下垂（保护不改动控制环）。
- **Ir=1000 / 门驱=12（`Constant=1000/12`）**：回到满辐照演示。
- **保护阈值按 48V 额定 % 取**（类比 §14.6）：UV≈70%×48、OV≈115%×48、OC 按本侧额定 3×；逻辑结构与 700V 完全一致（§20/§22.7）。具体数值以各模型保护子系统为准。
- 元件同 48V 通用（Cin_Bat 初值依所叠控制环，多为 24V）。

### 15.7 PV_Microgrid_shortcircuit.slx — 短路（48V）
- **定位**：注入母线/负载短路故障，验证保护动作与选择性（§4–§7 三关验收来源）。
- **PID(P=0.1, I=50)**：同下垂/保护。
- **门驱=12（`Constant1=12`）**；**Cin_Bat 初始=24V**（短路版，§22.2）。
- 短路电阻 R_fault、故障投切 Step_Fault 时间等以手册 A/B/C 关判据为准（§22.7）；保护阈值同 §15.6 的 48V % 取法。

### 15.8 PV_Microgrid_700V.slx — 700V 集成（终态，详细模型）
- **定位**：全集成 700V 三端口（PV/电池/负载），三关验收 PASS 的磁盘终态（Day14–15）。**完整参数来源见 §14**，此处按模型实值摘要：
- **电压/占空比常数**：`Vref_pv=432`（PV 侧目标，由≈11 块 37.8V 板串联定，§14.1）、`Vref_out=400`（Buck 输出）、`D_Boost_Open=0.383`（前馈，由 432→700 伏秒平衡 D≈0.383，§14.2）、`D_Buck_Open=0.571`（700→400）、`Ir=1000`（STC）。
- **三路 PI 终态增益**（怎么调来的见 §13）：`PI_Boost(2e-4, 0.1)`、`PI_Buck(1.5e-3, 0.3)`、`PI_DAB(5e-4, 2)`。
- **功率级**：L_Boost=3mH(0.05Ω)、Cin_PV=220µF(430V)、C_bus=470µF(700V)、Cin_Bat=470µF(240V)、C_Buck=100µF、C_block=100µF（隔直，§14.3/§14.9）。
- **保护**：UV490/OV805/OC_Bus43/OC_Bat20（§14.6）；Enable_Gate=15ms、TD_Confirm=30µs、GD_Boost 阈值 0.7/12（§14.7）。

### 15.9 PV_Microgrid_700V_avg.slx — 700V 平均模型（Day16，信号流）
- **定位**：把详细模型降阶为纯信号流"功率平衡日均模型"，用于快速跑 24h 多工况（Day16）。无 Simscape 元件，参数全在公式/常数里。
- **常数（`Ir=800, T=25, P_load_set=2000, V_bus=700, V_out=400, V_pv=432`）**：Ir=800 为典型日平均辐照（非满辐照）、T=25 常温、P_load_set=2000W 负载设定；电压常数与详细模型一致（§14.1/§14.5）。
- **PV 出力**：单二极管近似 `P_pv(Ir,T)`（§14.1 公式的信号流实现）。
- **电池/SOC**：`V_bat=200+80·SOC`（OCV∝SOC，§14.5）、`SOC` 由 `I_bat·Δt/Qnom` 积分（Qnom=50Ah）、Saturation 限 0.1~0.9。
- 无详细 PI/电容/保护——这是"平均模型"与"详细模型"的本质区别，跑的是能量平衡而非开关瞬态。
