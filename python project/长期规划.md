## 六、MATLAB/Simulink 项目细节 + 12 条可复用坑
- 700V：DAB(电池)稳母线 + Boost(PV CV) + Buck(负载)，电池 240V / 匝比 240/700 / 漏感 35µH。
- ⚠️ **可复用坑（重要）**：
  1. 电容预充必须勾 `vc_specify` 填 `vc`，只填 `v` 无效（母线从 0 慢爬）。
  2. 门极驱动 Simulink-PS Converter 用「零导数(分段常量)」模式，filter 字段灰显不生效。
  3. 沙箱跑 MATLAB 须 `dangerouslyDisableSandbox:true`，否则 0x80000003 启动崩。
  4. **绝不用 taskkill 强杀 MATLAB/服务宿主**——损坏许可证握手，需重启电脑。
  5. 向日葵(Oray)虚拟显示驱动致 MATLAB CEF 崩溃 → 禁用/退出向日葵 或 `-softwareopengl`。
  6. 提速：Solver Configuration 开 Local Solver(Backward Euler,1e-6) + 全局 ode1be + 关 Simscape 日志 + Accelerator。
  7. 诊断大模型：解压 .slx(zip)→读 `simulink/systems/system_root.xml` 做静态结构/参数分析（无头 MATLAB 不可用）。
  8. 脚本勿命名 `ver.m`/`exp.m`（遮蔽内置函数）。
  9. **MOSFET 驱动修复（SID 64-67、89-92）**：N 沟道 Gate 端口 Electrical 类型与 Simulink-PS Converter 输出不匹配，Vt≈4V、Relational Operator 仅 1V 无法驱动 → 插 **Gain=15** 抬到 ~15V 超 Vt。
  10. **主环 PID 基线**：P=0.5, I=0.2, D=0（PI 模式），Vbus 稳 700V。
  11. **DAB 相移 Rate Limiter 调参**：slew-rate sweep（slew ∈ {0.5, 1, 2, 5, 10}）筛选最优动态性能。
  12. **MATLAB R2025b 细节**：To File 模块用 `MatrixName` 参数；Simscape 物理连线在块 `PortConnectivity` 属性。
